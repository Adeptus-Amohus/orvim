# Orvim — сайт и публичные выпуски

Сайт: https://adeptus-amohus.github.io/orvim/

Статический сайт для знакомства с Orvim, скачивания публичного выпуска и обратной связи. Проверенный адрес сайта и файлов распространения — `Adeptus-Amohus/orvim`. На 11 ноября 2026 года опубликованы Orvim 0.4.46, установщик Windows x64 EXE и Android ARM64 APK. Сайт находится в site/ основного репозитория Orvim рядом с приложением и документацией. Адрес сайта сохраняется.

## Публикация

Для текущего отдельного сайта документирована схема GitHub Pages: ветка `main`, папка `/` (корень), режим `Deploy from a branch`. `.nojekyll` отключает обработку Jekyll. Сборка и зависимости не нужны. Не применяйте эту схему автоматически после изменения структуры основного репозитория: сначала согласуйте место назначения.

Источником публикации служит папка `site/`. Workflow сохраняет относительные пути и `.nojekyll`. Не копируйте `.git`, `.artifacts`, базу пользователя, секреты или весь репозиторий приложения. Не заменяйте README основного приложения этим файлом: он относится только к сайту.

## Сборки приложения

[Стабильный Orvim 0.4.46](https://github.com/Adeptus-Amohus/orvim/releases/tag/v0.4.46): [Android ARM64 APK](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/Orvim-0.4.46-Android-arm64.apk), [Windows x64 EXE](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/Orvim-0.4.46-Windows-x64-setup.exe), [инструкции](https://github.com/Adeptus-Amohus/orvim/blob/main/docs/INSTALLATION.md), [SHA-256](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/SHA256SUMS.txt). Скачивание без авторизации.

Commit исходников приложения: `d632f6b0d536968b1564fcdd0abfe6c4d6b95d55`. Публичный тег этого репозитория обозначает материалы распространения и сайт, а не исходники приложения. [Происхождение и проверки](docs/RELEASE_0_4_46.md). [Отчёт анонимного скачивания и проверки сайта](distribution/public-download-verification-0.4.46.json).

`release.json` содержит ссылки на проверенные публичные файлы в Releases этого репозитория. Для 0.4.46 прямые ссылки также записаны в HTML: скачивание работает без JavaScript и при недоступности JSON.

После публикации APK/EXE укажите `version`, `windows`, `android`, `notes` и при необходимости `notice`. Windows — установщик x64, Android — APK ARM64. Не указывайте ссылки на приватный репозиторий: посетитель не сможет скачать файл. Версия исходников не является подтверждением версии установщика.

## Проверка

В рабочем репозитории приложения: `node scripts/verify-site.mjs`. Для локального просмотра можно запустить любой статический HTTP-сервер из `site/`. Сайт работает под префиксом `/orvim/`; пути к ресурсам относительные.

Проверьте навигацию, три вкладки, увеличение снимка и закрытие по Escape, FAQ, ссылки отзывов и состояние скачивания на широком и узком экране.

Обновлённый сайт содержит краткую установку и обновление, отдельное предупреждение о смене подписи тестовых Android APK и публичную подробную инструкцию. Наличие шифрования базы не делает внутренние копии переносимыми: перед переустановкой нужна проверенная копия с паролем. Анонимное скачивание APK/EXE и контрольные суммы проверяются отдельно от сборки приложения. Результаты текущей работы: `materials/site/github-refresh-result.md` в рабочем репозитории, вне публикуемого пакета.

## Материалы

Снимки интерфейса: текущие модули Orvim 0.4.46, 11 ноября 2026 года. Реальный интерфейс в браузерном стенде, вымышленные данные. Мобильная компоновка — 390 px, не снимок установленного APK. Готовые `home-desktop.jpg`, `home-mobile.jpg`, `projects-desktop.jpg` скопированы из `materials/design/github-refresh/` после появления `HANDOFF.md`; исходная папка не изменялась. Прозрачный знак `orvim.png` совпадает с переданным ресурсом и сохранён без изменений.

Первый экран тура использует `picture`: до 600 px показывается мобильный кадр, далее — настольный. Соотношения сторон сохранены, кадры не обрезаются. Увеличение открывает показанный вариант изображения. Отдельные вкладки проектов и мобильной компоновки сохранены, hero продолжает использовать композицию ПК + телефон без дублирующего баннера.
