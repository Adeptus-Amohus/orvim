Приватность сайта

Что делает эта страница

Сайт Orvim — статическая страница на GitHub Pages. В коде сайта нет аналитических счётчиков, рекламных скриптов, форм сбора персональных данных или собственных cookies. Шрифты и изображения загружаются с того же сайта.

Сайт не получает доступ к базе установленного приложения. Для отображения ссылок на сборки он читает небольшой файл release.json с того же адреса.

Хостинг и внешние ссылки

GitHub обслуживает сайт и может обрабатывать технические данные запросов, например IP-адрес, согласно своей политике приватности. При переходе в GitHub Issues или Releases действуют условия GitHub.

Обратная связь

Кнопка «Написать об Orvim» открывает черновик письма в вашем почтовом приложении. Вы сами решаете, что написать и когда отправить письмо. Сообщения об ошибках в GitHub видны публично. Не прикладывайте личную базу, медицинские или финансовые записи, пароли, ключи и скриншоты с чужими данными. Используйте вымышленные примеры.

Данные приложения

Основные данные Orvim хранятся на устройстве. В установленном приложении база и внутренние автоматические копии зашифрованы ключом устройства. Для переноса и восстановления после переустановки нужна отдельная копия с паролем; заранее проверьте её восстановление.

Обычный экспорт JSON/CSV, отдельно сохранённые вложения и браузерный предпросмотр остаются открытыми. Старые внешние копии автоматически не перешифровываются. Защита устройства и места хранения копий остаётся важной.

Внешние подключения включаются по выбору пользователя. При отправке сообщения ИИ передаются запрос, переписка и выбранный контекст; другие подключения передают данные соответствующего действия. У сторонних сервисов свои условия обработки данных.
