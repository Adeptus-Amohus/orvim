## Изменения приложения

Включены актуальные изменения 0.4.24–0.4.45: шифрование базы и автоматических копий; переносимые копии с паролем; LAN/файловый перенос и проверка импорта; личный день, сон, питание, вес, самочувствие и статистика; русский/английский интерфейс и исправления форм; Android-виджеты расписания/задач, мысли и компактного питания; Windows-трей; разделённая загрузка интерфейса и отправка ИИ-сообщений с вручную выбранными данными. Изменения ИИ применяются после подтверждения.

0.4.46 добавляет постоянную Android release-подпись, согласованные версии, проверенный NSIS-установщик, инструкции перехода и полный комплект уведомлений зависимостей. Публичное размещение не меняет двоичные файлы этой версии.

## Проверки готовых файлов

- Android: release/R8, без `debuggable`, `testOnly` и зависимости от Vite; versionName 0.4.46, versionCode 4046, только ARM64. Постоянная подпись v2/v3 проверена; все ELF LOAD-сегменты имеют 16-КиБ выравнивание, библиотека в APK совпадает с компиляцией.
- На отдельном API 36 x86_64 эмуляторе с ARM64-трансляцией проверены установка, перенос синтетической записи из 0.4.45 через защищённую копию, сохранение записи после замены пакета и перезапуска, шесть нативных хостов виджетов. Это не проверка физического ARM64 или всех OEM-лаунчеров.
- Windows x64: установка поверх существующей 0.4.43, запуск, удаление и повторная установка; файлы базы и защищённых ключей сохранились по SHA-256. Ярлыки и ресурс значка проверены. Финальный EXE запущен; встроенный полный комплект лицензий сохранён и побайтово совпал с подготовленным комплектом.
- EXE не подписан Authenticode. Проверка проведена на существующем Windows-профиле с WebView2; чистая ОС без runtime не проверялась.
- Пройдены UI-набор, Rust fmt/check/Clippy, 71 Rust-тест (0 ошибок, 2 внешних smoke-теста обложек ignored), сверка 92 координат Android runtime. CI Windows и Android исходной версии завершился успешно.

Физический телефон, реальные 90/120 FPS, живые внешние ИИ/Google/Notion/Health Connect и все версии поддерживаемых ОС не проверялись. Браузерные сценарии ИИ/импорта использовали синтетические сервисы. [Установка и безопасное обновление](INSTALLATION.md), [подпись Android](ANDROID_SIGNING.md), [лицензии](LICENSES.md).

## Сведения о сборке

Использованы Node 24.21.0/npm 11.19.0, Rust 1.98.1, Tauri CLI 2.11.5, JDK 21, SDK/Build Tools 36, NDK 30.0.16248370, Gradle 8.14.3, Android Gradle Plugin 8.11.0, NSIS 3.11. Зависимости исходного снимка закреплены lockfiles. Типовые команды из полного исходного checkout: `npm ci`, `npm run licenses:check`, `npm run test:ui`, `npm run rust:test`, `npm run rust:lint`, `npm run tauri -- build --bundles nsis --ci`, `npm run android:build -- --apk --target aarch64 --ci`.

Разработка требует доступа к исходникам, MSVC/Windows SDK для Windows и JDK/SDK/NDK для Android. На Linux для OpenSSL явно задаются LLVM clang/ar/ranlib NDK и API 24; на Windows Android-сборка требует Unix-совместимый Perl и NDK Make. Подпись выполняется существующим постоянным keystore через безопасное окружение. Секреты в документацию не включены. Побайтовая воспроизводимость между различными компиляторами/средами не обещается; происхождение распространяемых файлов подтверждается указанными commit и SHA-256.
