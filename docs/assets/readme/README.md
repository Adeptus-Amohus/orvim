# Оформление README

Баннер, керамический знак, слоган «A foundation for your success» и четыре локальные метки сохранены из прежнего README приложения. PNG — экспорт прежнего SVG; `hero-mobile` использует ту же графику в компактной раскладке.

11 ноября 2026 года направление оформления подготовило свежие снимки текущих модулей 0.4.46: `home-desktop.jpg` (1280 × 720), `home-mobile.jpg` (390 × 844), `projects-desktop.jpg` (1280 × 900). Композиция `interface.svg`/`interface.png` сохраняет прежнюю витрину ПК + телефон. В README используются PNG и отдельный мобильный JPG до 600 px; полные снимки доступны по ссылкам.

Реальный интерфейс в браузерном стенде, вымышленные данные. Мобильная компоновка — 390 px, не снимок установленного APK. Демонстрационные дата и время фиксированы на 11.11.2026, 11:00, Asia/Qyzylorda. Личная база не использовалась; внешняя сеть стенда блокировалась. Эти кадры не подтверждают нативные API, SQLite, APK/EXE, виджеты или физический телефон.

Материалы взяты из завершённого HANDOFF направления оформления; исходные рабочие файлы этого направления при интеграции не редактировались. Использование отдельного постоянного пути `docs/assets/readme/` сохраняет структуру прежнего README и не добавляет личные локальные стенды в основной проект.
