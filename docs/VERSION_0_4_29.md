# Orvim 0.4.29

- Добавлен перенос через защищённый файл: «Настройки → Данные → Перенос по USB». На исходном устройстве создаётся файл с паролем; после копирования по кабелю он открывается в Orvim на принимающем устройстве. Это файловый перенос, а не автоматическая синхронизация при подключении USB. На Android нужен режим «Передача файлов»; отладка USB не требуется.
- При приёме сначала появляется сравнение. Совпадающие записи объединяются, новые предлагаются к добавлению, для конфликтующих версий нужен явный выбор: «Оставить на этом устройстве» или «Использовать из файла». Пока выбор не сделан, применение недоступно. Отсутствующие в файле записи не удаляются. Повторное применение одного файла не создаёт копии.
- Файл не содержит API-ключей, истории ИИ и оформления. Пароль нужен на обоих устройствах. Перед применением сохраняется резервная копия. Журнал файлового переноса хранится отдельно от журнала LAN и удаляется полным сбросом данных.
- Сравнение разбито на страницы по 50 записей; выбор сохраняется при переключении страниц. Индексированное объединение проверено на 10 000 одинаковых записей с разными локальными номерами.
- Исправлена ошибка `archiveItems` при добавлении еды через ИИ после синхронизации. Отсутствующая оценка или отзыв считаются незаполненными необязательными полями, как и в нативном хранилище. Проверка допустимых оценок и типов сохранена.
- Вместо `@settings` показывается название настройки и единицы: «Дневная цель калорий», «2600 ккал в день», «Цель не задана».
- В Android добавлена кнопка сканирования QR внутри приложения. ZXing обрабатывает изображение на устройстве; камера запрашивается при запуске сканера. Внешние ссылки подключения сохраняются, если интерфейс ещё загружается. Сканирование заполняет форму и требует подтверждения подключения.
- На Windows добавлена проверка разрешающих правил брандмауэра. Кнопка исправления запрашивает подтверждение Windows и создаёт правила только для текущего Orvim, TCP 42673 и UDP 42674, частного профиля и локальной подсети. Для текущей установки эти два ограниченных правила были добавлены при диагностике; после повторного поиска пользователь подтвердил успешный обмен.
- Дополнена таблица встроенных иконок Windows/Android для новых элементов настроек.

Реальный кабельный перенос и камера физического телефона требуют отдельной пользовательской проверки. Выпуск в интернете не публиковался; предыдущие установочные пакеты сохранены.
