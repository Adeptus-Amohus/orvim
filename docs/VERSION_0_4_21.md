# Orvim 0.4.21 — занятия, данные для ИИ и питание

17 октября 2026 года. Формат документа 31, SQLite 3 и протокол LAN 3 сохранены.
Реальная пользовательская база и ключи сервисов не открывались. Выпуск 0.4.20 сохранён.

## Главная и тренировки

- На главной у занятия показан компактный счётчик упражнений и один таймер.
  Список упражнений больше не разворачивается внутри списка задач.
  Нажатие на счётчик открывает отдельное окно со всеми упражнениями и подходами.
- Массовое удаление доступно в «Жизнь → Тренировки → План и результаты»
  по кнопке списка с галочками. Также оно есть в меню занятия и в окне результатов,
  которое открывается из расписания.
- Можно выбрать все занятия или отдельную серию, даты начала и конца, нужные записи.
  «Выбрать все» включает все найденные записи, в том числе за пределами первого
  экрана и текущего месяца. Список отображается порциями по 100 строк.
- Выполненные занятия по умолчанию исключены. Для их удаления есть отдельный
  переключатель. Записи, импортированные из Health Connect, в этот список не входят.
- Перед удалением показано количество; подтверждение удаляет занятия и связанные
  события расписания. Кнопка «Отменить» восстанавливает их вместе. Записи, добавленные
  после удаления, при отмене сохраняются.
- Новые повторы получают общий идентификатор серии. Старые планы группируются
  по названию, времени, длительности и составу упражнений, а не по одному названию.
- Таймер удалённого занятия останавливается без сигнала об окончании отдыха.

## Доступ ИИ к базе данных

Причиной ответа «не вижу фильмы и книги» был пустой выбранный контекст.
Открытие страницы базы само по себе не передаёт её содержимое провайдеру ИИ.

- В чате появилась отдельная кнопка «База данных»; в выборе источников этот раздел
  также доступен сразу, без «Ещё».
- Пока записи не выбраны, чат пишет «Без записей Orvim».
- При упоминании существующего названия или запросе к базе приложение локально
  предлагает прикрепить подходящие записи. До нажатия «Прикрепить и отправить»
  они не отправляются. Можно выбрать вручную или продолжить без них.
- ИИ получает настоящие идентификаторы, категории, оценки и настройки шкалы
  выбранных коллекций. Нужную запись можно исправить вместо создания дубликата.
  Выбор всего раздела включает также определения пустых коллекций.
- Выбор сохраняется и виден в строке контекста. Его можно убрать через
  «Добавить контекст → Убрать всё». Другие невыбранные разделы не прикрепляются.
- Изменения ИИ остаются предложениями с предварительным просмотром.

## Питание и калории

- В редакторе еды есть явная кнопка «Удалить запись». Удаление убирает запись,
  её калории и БЖУ из итогов дня; доступна отмена.
- При запросе об исправлении питания предлагается прикрепить соответствующие
  записи. Для запроса без названия используются сегодня, «вчера» или явно указанная
  дата YYYY-MM-DD. В ручном выборе можно прикрепить любую дату.
- После прикрепления ИИ может предложить удалить существующую запись или изменить
  калории и БЖУ. Отрицательные значения не принимаются. Неясное «убери калории»
  требует уточнить запись и количество.
- Исправлено повторное открытие устаревших значений «на 100 г» после изменения
  съеденной порции через ИИ.

## Как работает микрофон

Это диктовка текста, отдельная от модели чата. Выбранный DeepSeek, GPT или Gemini
получает распознанный текст только после отправки сообщения. Orvim не записывает
аудиофайл и не отправляет аудио через API выбранного ИИ.

- **Android:** сначала используется `createOnDeviceSpeechRecognizer`, если устройство
  его поддерживает. При явном разрешении облака допускается системная служба Android:
  она сама определяет локальную или сетевую обработку. Аудио в этом режиме может
  передаваться поставщику системной службы. Его название, если доступно, и фактический
  режим теперь показаны под полем сообщения. Физический аудиовход выбирает система.
- **Windows:** локальный `System.Speech` и системный микрофон по умолчанию;
  нужен совместимый установленный речевой пакет.
- **Браузер:** служба распознавания браузера может использовать облако, поэтому
  требуется явное разрешение. Это не служба выбранного в чате ИИ.
- Ошибка диктовки с кодом 13 на старом скриншоте означает отсутствие доступного речевого
  пакета выбранного языка. Она не означает ошибку DeepSeek. Новая версия показывает
  понятное сообщение; на поддерживаемом Android доступна кнопка установки пакета.
  Ошибка запуска не оставляет приложение в ложном состоянии «микрофон включён».

Поведение API сверено с [документацией Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer).
Фактический поставщик и наличие языковой модели зависят от телефона.

## Проверки

- 23 новые проверки DOM/событий: компактная главная, все семь упражнений,
  удаление 199 из 200 занятий с сохранением выполненного, отмена и связи событий,
  прикрепление базы после выбора, изменение оценки существующей записи,
  изоляция невыбранных разделов, удаление еды и отмена.
- 28 проверок чистой логики: отбор контекста, стабильные идентификаторы, шкала оценки,
  даты питания, исправление порции, удаление еды, группировка повторов, сохранение
  результатов и импорта, повторная отмена, ошибка запуска диктовки.
- Стресс: удаление и восстановление 100 000 занятий и 100 000 связанных событий.
  Это тест модели данных, а не измерение плавности интерфейса телефона.
- Полный набор `npm run test:ui` и TypeScript пройдены. Rust: 48 тестов пройдены,
  1 служебный тест пропущен. После последней правки подтверждения повторно пройдены
  все 23 новые проверки интерфейса. Финальные Windows и Android сборки успешны.
- Телефон, реальный микрофон, внешний аккаунт ИИ, инерция жестов и интерфейс
  установщика вручную не проверялись. В тестах используются искусственные данные
  и имитация системных сервисов; результат генерации конкретной модели ИИ не гарантируется.

Сборки: `releases/0.4.21/`. Версии, подпись APK, 16 КБ выравнивание, библиотека ARM64,
содержимое frontend и контрольные суммы фиксируются в `build-info.json`.
