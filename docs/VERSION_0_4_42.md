# Orvim 0.4.42 — питание в одной строке рабочего стола

- Виджет питания теперь заявляет размер 2 × 1 ячейки вместо 2 × 2. Минимальная высота уменьшена с 132 до 56 dp; растягивание отключено.
- Карточка заполняет выделенную область: под ней нет скрытого пустого контейнера. Калории, дневная цель и прогресс уплотнены; справа находится кнопка «+» для добавления еды. Нажатие на карточку тоже открывает ввод еды.
- Цветовая тема и работа редактора еды сохранены.

После обновления откройте Orvim, удалите старый виджет питания с рабочего стола и добавьте его заново. Лаунчер хранит размер существующего экземпляра; новый виджет получает область 2 × 1, чтобы под ним можно было разместить запись мысли.

Размер ячеек зависит от сетки домашнего экрана и лаунчера. Настройка стандартного размера реализована через [Android AppWidgetProviderInfo](https://developer.android.com/develop/ui/views/appwidgets/layouts).

Локальный Android APK с прежним тестовым сертификатом; без публикации и без новой сборки Windows.
