# Проверка Orvim 0.4.37

5 ноября 2026. Android ARM64, локальная сборка.

- TypeScript и production-интерфейс собраны успешно.
- 4 теста данных виджетов: даты задач, события, личный день питания, смена даты/языка, исключение ключей и текстов мыслей из проекции.
- Браузерная проверка настоящего runtime: создание задачи, новая мысль, ручное питание, дата еды, фокус ввода, завершение задачи, повтор команды без обратного переключения и открытие редактирования. Ошибок JavaScript нет.
- Дополнительно прошли 12 проверок чата с клавиатурой и 24 проверки английского языка. 5 тестов сохранения перед закрытием окна также прошли.
- Kotlin, ресурсы, release lint и сборка APK через Gradle завершились успешно.
- Подпись APK проверена; сертификат совпадает с 0.4.36. Проверены ID пакета, версия 0.4.37/4037, ARM64, три провайдера виджетов, отсутствие RECORD_AUDIO, ZIP и ELF-выравнивание 16 КБ, совпадение нативной библиотеки и актуальных frontend assets. Размер/хеш — build-info.json.
- APK 0.4.36 сохранён без изменения (SHA-256 совпал с прежним build-info).
- На физическом телефоне и эмуляторе эта сборка не запускалась. Проверки переходов выполнены в браузере, а не в Android launcher. Реальные размеры клеток, первичное добавление/масштабирование виджетов, закрытое приложение, экономия батареи и периодическое обновление требуют проверки на устройстве.
- Схема личной базы не менялась. Публикации и Windows-сборки нет.
