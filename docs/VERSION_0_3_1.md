# Life OS 0.3.1 — значки

- Нативный значок Windows и Android заменён выбранным керамическим додекаэдром.
- Внутри приложения используется упрощённый SVG того же направления: однотонные грани, круглые отверстия и небольшие детали на вершинах.
- Оттенок SVG зависит от палитры, включая пользовательский цвет; светлый и тёмный режимы используют разные оттенки и контуры.
- На телефоне значок добавлен в шапку. На ПК он остаётся в боковой панели.
- Для адаптивного значка Android предусмотрены внутренние отступы.

Сборка выполняется локально из рабочего дерева. Проверки компиляции входят в сборку; дополнительные тесты поведения в этой итерации не запускались. Внешний вид в физическом телефоне требует просмотра установленной APK.

Визуальный пример сочетаний тем находится в `.artifacts/brand-ceramic/ui-preview.png`. Это изображение реальных SVG из кода приложения, а не скриншот запущенной APK.
