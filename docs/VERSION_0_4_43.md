# Orvim 0.4.43 — полный английский интерфейс и питание

- Дополнен перевод служебных надписей, статусов коллекций, действий с мыслями и материалами, сообщений импорта, обновлений, резервных копий и проверок данных. Дополнительный каталог содержит 270 подписей и сообщений.
- Исправлены динамические подписи: kcal, kg, g, ml, часы, подходы и повторения, размер файлов, история резервных копий, статусы разрешений Android и подключения к ПК.
- Выбор English имеет приоритет над языком системы. Для экранов загрузки и ошибок до открытия базы отдельно запоминается только настройка языка; личные записи в этот кэш не входят.
- Даты в истории резервных копий используют язык интерфейса. Подписи даты обновляются при восстановлении документа.
- Нативные окна виджетов, выбор даты и сообщения ошибок следуют выбранному языку. Системные окна Android, которые открываются вне Orvim, могут использовать язык ОС.
- Названия и содержимое пользовательских записей не переводятся и не переписываются.
- В питании возвращены более крупные цифры и свободное расположение текста. Размер на рабочем столе остаётся 2 × 1: заголовок сверху, калории и дневная цель рядом ниже, прогресс внизу.

Локальные APK и EXE для проверки, без публикации. APK подписан прежним тестовым сертификатом. После обновления откройте Orvim один раз для обновления виджетов.
