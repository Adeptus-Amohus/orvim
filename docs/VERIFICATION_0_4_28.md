# Проверка Orvim 0.4.28

## Проверено

- 61 нативный Rust-тест прошли, 2 теста внешнего поиска обложек намеренно не запускались. Clippy без предупреждений к исходному коду.
- В синхронизации добавлены регрессии: два одноимённых проекта, две задачи с одинаковым ключом повторения, сохранение явных ссылок на проекты, повторный обмен и перезапуск журнала. Старый псевдоним не может забрать канонический идентификатор другой записи.
- Существующие тесты LAN включают реальный TCP loopback, неверный код/ключ, изменение зашифрованного сообщения, повтор старого сообщения, отзыв устройства, 10 000 задач и повторный обмен после перезапуска.
- Полная `npm run test:ui` и 23 Node-теста прошли. Проверка типов и сборка web-части прошли.
- 168 проверок браузера: 36 прежних проверок настроек и 132 новых. Ширины 320, 390, 1020 и 1280; новые проверки в светлой и тёмной темах. Проверены скрытые технические сведения, действующий/истёкший код, видимость ошибок, действия сервера/клиента, защищённая копия и открытый JSON, отсутствие горизонтального переполнения и стабильная высота статуса при обмене.
- Изображения нового раздела получены из работающего интерфейса с синтетическими данными. Персональная база пользователя не изменялась.

## Границы проверки

Браузер использует подменённые нативные сервисы, а сетевые тесты работают локально на одном ПК. Реальная пара телефон/ПК через роутер, физический телефон, интерфейс Windows-установщика и внешние AI-аккаунты в этой версии не проверялись. На эмуляторе эта версия отдельно не запускалась. Новые выпуски в GitHub не публиковались.

Сведения о подписи, размере, контрольных суммах и составе итоговых пакетов находятся в `releases/0.4.28/build-info.json` после упаковки.
