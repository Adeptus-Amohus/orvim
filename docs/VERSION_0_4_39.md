# Orvim 0.4.39 — виджеты и КБЖУ

Локальная тестовая сборка Android. Обновляется поверх 0.4.38 с прежней подписью.

- На Android 12 и новее расписание передаёт готовые строки часов и задач через RemoteCollectionItems. Для старых Android сохранён RemoteViewsService.
- Виджет мысли отображается без чтения зашифрованной базы. Разметка виджетов явно использует стандартные Android-компоненты, чтобы оболочка телефона не подменяла их несовместимыми элементами.
- Обновление виджетов обрабатывается в фоне с контекстом приложения.
- В окне питания можно добавить несколько блюд, указать калории, белки, жиры и углеводы. БЖУ необязательны.
- Оценка ИИ заполняет редактируемые поля каждого блюда. Можно исправить название и числа, удалить ненужные блюда и затем сохранить оставшиеся. Автоматического сохранения ответа ИИ нет.
- Значения проверяются перед сохранением и при переносе в основную базу; БЖУ из виджета больше не заменяются нулями.

После обновления откройте Orvim один раз. Если Android продолжает показывать ошибку старого виджета, удалите его с домашнего экрана и добавьте заново.

Как и в 0.4.38, записи сразу сохраняются в зашифрованном журнале на устройстве; в основную базу, её резервные копии и синхронизацию они попадают при следующем открытии Orvim.

Android API: [RemoteCollectionItems](https://developer.android.com/reference/android/widget/RemoteViews.RemoteCollectionItems.Builder), [поддерживаемые компоненты RemoteViews](https://developer.android.com/reference/android/widget/RemoteViews).
