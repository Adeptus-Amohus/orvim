# Orvim 0.4.14 — добавление в блоке задач и ответы ИИ

12 октября 2026 года. Формат данных 31, схема SQLite 3 и протокол LAN 3 сохранены.

## Изменения

- Кнопка «+» перенесена из заголовка «Главная» в верхнюю правую часть блока задач, перед датой. Выбор «Задача» / «Мысль» и возврат фокуса после закрытия остаются доступными.
- DeepSeek получает поля записи обычным JSON-объектом. Приложение само преобразует его в внутренний строковый формат, сохраняя проверку допустимых полей, типов и значений. Модели больше не нужно вручную экранировать JSON внутри JSON.
- Предыдущие сообщения ИИ при отправке DeepSeek используют тот же JSON-конверт, что требуется для нового ответа. Сам чат продолжает показывать обычный текст.
- Проверяется причина остановки генерации: обрыв по лимиту длины, отказ и прерывание сервиса различаются. Даже корректный фрагмент с признаком обрыва не принимается как завершённый ответ.
- При пустом, незавершённом или некорректном ответе DeepSeek выполняется одна повторная генерация с требованием краткого полного JSON. Максимум две генерации на сообщение; сетевые ошибки и отказы автоматически не повторяются. API учитывает повторную генерацию как дополнительный запрос.
- Ответ DeepSeek ожидается до трёх минут на попытку. Во время ожидания чат показывает «Готовит ответ…», затем «ИИ ещё готовит ответ…». Ожидание само не создаёт ошибку JSON. По завершении таймер очищается.
- Поддерживаются завершённые блоки `json / `JSON и BOM. Повреждённые данные не дописываются предположениями и не выполняются. Изменения записей по-прежнему показываются для подтверждения.
- Сетевая ошибка ожидания отделена от недоступности соединения. При неудаче сообщение остаётся в переписке с кнопкой «Повторить».

## Проверки и границы

Пять тестов `assistant::tests` прошли: обычные объекты и прежние строковые записи; обрыв и пустой ответ; некорректный формат; отказ провайдера; отклонение неизвестных полей, неверных типов, дат и диапазонов. Это локальные проверки с искусственными ответами, без обращения к API и пользовательской базе.

В браузерном макете проверены новое положение «+» и открытие меню. Изображение — `.artifacts/home-add-0.4.14-preview.png`.

Точная причина конкретного ответа со скриншота неизвестна: исходный ответ провайдера и причина завершения не сохранены. Исправления обрабатывают обнаруженные классы ошибок, но не гарантируют отсутствие любых ошибок модели. Живой запрос с ключом пользователя, физический Android-телефон и установленное Windows-приложение не проверялись. Полные UI- и стресс-тесты не запускались.

Пользовательская база и ключи не открывались и не менялись. Предыдущая версия 0.4.13 сохранена отдельно. Android использует прежний идентификатор и сертификат обновления.

Справка провайдера: [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) описывает возможный обрыв JSON при finish_reason=length. Сообщение «Модель вернула некорректный JSON» в прежнем коде возникало только после получения и разбора HTTP-ответа.

Сборки Windows x64 (установщик и EXE) и Android ARM64 завершены. Проверены версия 0.4.14, прежний сертификат APK, выравнивание APK и актуальные ресурсы интерфейса внутри обоих нативных файлов. Результаты и SHA-256: releases/0.4.14/build-info.json.
