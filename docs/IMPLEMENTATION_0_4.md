## План и состояние

1. Сохранение: устранён пропуск возврата к предыдущему значению во время записи; неизвестный формат вызывает ошибку вместо пустого состояния; убрана запись дефолтного снимка при открытии; SQLite synchronous FULL. В проверенной установленной SQLite (только целостность/счётчики, без вывода содержания) есть по одной записи projects/tasks/thoughts, integrity ok. Это не доказывает первопричину случая пользователя.
2. Главная: только локальная сегодняшняя дата + корректное время. Создание заранее и дата создания не используются как назначение; проверен переход через полночь. Задачи со временем ранее представлялись сущностями events, обе коллекции учитываются.
   3–5. Реализованы: отдельные источники и записи, задачи проекта, сохранённые наборы контекста, актуализация и предпросмотр; Markdown чат; общий JSON реестр команд JS/Rust, запрет неизвестных полей/ID/связей, атомарное применение и отмена, открытие созданного проекта. 24 проверки ассистента и 20 проверки команд проходят.
3. Реализованы сеансы Windows System.Speech / Android SpeechRecognizer до Stop, перезапуск после пауз, локальный движок / явное согласие на облачный, частичный текст. Мок диктовки проходит; физический микрофон не проверен.
   7–8. Реализованы интерфейсы Ethernet/Wi-Fi, UDP обнаружение, QR/deep link с ID, сравнение до замены, журнал отклонений; WebDAV зашифрованный журнал + ETag CAS. Нативный повтор после отклонения проходит; роутер и живой внешний WebDAV ещё не проверены.
4. В работе: атомарные JSON копии каждый час при изменениях, максимум 24; согласованный VACUUM INTO перед миграцией/сменой версии; Windows Documents/Life OS/backups, Android private до выбора SAF папки; проверка восстановления и интерфейс управления.
5. Реализованы Ed25519 подписанный манифест, SHA-256 пакета, прогресс, Windows установщик/Android системный APK установщик с проверкой сертификата, совместимость схемы и prebackup. Проверка подписи/подмены тестируется. Production trust key и опубликованный манифест отсутствуют; установка заблокирована до настройки. Android downgrade ограничен системой, требует внешней копии/переустановки, не автоматизирован.
6. Добавлены Apache-2.0 LICENSE, metadata, NOTICE, раздел приложения и сборщик лицензий сторонних пакетов. Правообладатель не придуман.

Подтверждено на этапе 1–2: persistence 15 assertions, today 4 assertions, TypeScript. Полные сборки и native UI/restart/force-kill тесты ещё впереди. Реальный телефон, перезагрузка устройства и роутер не проверены.

Финальная проверка: 441 UI assertions, 42 Rust tests, Chrome 30 новых + 108 production проверок. Нативный TCP/UDP, зашифрованный WebDAV/ETag гонка, durable rejection, обе копии и удаление без воскрешения, JSON/SQLite восстановление, реальный force-kill тестового дочернего процесса, 10 000 задач, Ed25519/подмена/хеш проходят. Из исходников собираются Windows EXE/NSIS и Android ARM64 APK; установку на устройствах и production-доставку обновлений не заявляем проверенными.

При упаковке Vite dev watcher завершился с EBUSY на новом EXE в `releases`; это ошибка тестового сервера, не установленного приложения. Добавлены watch exclusions для `releases` и `.artifacts`; после перезапуска 30 browser проверок вновь проходят. Тест закрывает собственный Chromium и при ошибке подключения.
