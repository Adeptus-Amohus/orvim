# Проверка Orvim 0.4.45

10 ноября 2026. Локальные Windows и ARM64 Android сборки; публикации нет.

- Удалены автоматический вызов предложения контекста, его панель и стили. Отправка использует уже выбранный вручную контекст. Дополнительные записи автоматически не прикрепляются; ручной выбор через «Данные для ИИ» сохранён.
- `npm run test:ui` прошёл. Прежние проверки прикрепления переведены на явный выбор данных; проверки приватности, предпросмотра, применения, отмены и сохранения сохранены.
- `node tests/browser-assistant-direct-send.cjs` прошёл на ширинах 390 и 1280 px: два последовательных сообщения о питании без промежуточного меню; невыбранная еда отсутствует в запросе; предложение не меняет базу до применения; применение создаёт ровно одну запись; явно выбранные данные передаются. Использованы синтетические ответы и хранилище, без обращения к реальному ИИ. Скриншоты `.artifacts/tray/assistant-direct-send-*.png` просмотрены.
- Генератор `node scripts/export-tray-icon.mjs` создаёт отдельный 64 × 64 RGBA значок трея из исходной керамики, с удалением прозрачных полей. При контрольном уменьшении до 16 × 16 px область alpha ≥ 128 выросла с 12 × 12 до 15 × 16 px. Проверен сравнительный снимок `.artifacts/tray/size-comparison.png`; это проверка растрового ресурса, не измерение реального трея Windows.
- `npm run desktop:build` успешно. Проверены ProductVersion `0.4.45`, наличие точной RGBA-последовательности нового значка в EXE и имён всех четырёх актуальных JS/CSS-файлов. Артефакт `releases/0.4.45/Orvim-0.4.45-Windows.exe`.
- `npm run android:build -- --target aarch64 --apk --ci` успешно с JDK 21, SDK 36 и NDK 30. Для локальной сборки использован IPv4-параметр JVM; глобальные настройки не менялись.
- APK выровнен и подписан прежним личным тестовым сертификатом. `apksigner verify --verbose --print-certs` и `zipalign -c -P 16 4` прошли. Сертификат совпадает с фактическим APK 0.4.44. Идентификатор `local.lifeos.client`, versionName `0.4.45`, versionCode `4045`, единственная ABI `arm64-v8a`.
- Все ELF LOAD-сегменты новой библиотеки имеют выравнивание `0x4000`. SHA-256 библиотеки из APK совпадает с собранной библиотекой. В ней проверены имена актуальных разделённых файлов загрузки и рабочего пространства; в DEX присутствует вызов `setRequestedFrameRate`. Компоненты трёх виджетов и отдельного ввода сохранены в манифесте.
- Старый APK 0.4.44 не изменён: SHA-256 `9C03CDAB082EB968DF743B1FCAAD58AADA1B364E0B5C1ED13EAA8FEF0063FFF7`.

Контрольные суммы новых файлов и результаты: `releases/0.4.45/build-info.json`, `apk-signature.txt`, `apk-metadata.txt`, `apk-manifest.txt`. Логи: `.artifacts/build-0445-android.log`, `build-0445-windows.log`, `verify-0445-apk.log`, `test-0445-ui.log`.

Новый APK на эмуляторе и физическом телефоне не запускался. Реальные 90/120 FPS, установка поверх текущей версии на телефоне и фактическое отображение нового значка в системном трее отдельно не проверены. Изменения не требуют удаления установленного приложения; совместимость подписи проверена.
