# Orvim 0.4.6 — новое название и значок Windows

Life OS переименован в **Orvim**, как в презентации проекта. Изменены имя Android-приложения, заголовок окна Windows, установщик, подписи интерфейса, поиск, системные уведомления Windows, сообщения подключений и ИИ. Керамический значок остаётся прежним.

## Почему в поиске Windows пропал значок

В установленной версии 0.4.5 ярлык меню «Пуск» указывал на `life-os-ceramic-0.4.5.ico`, тогда как установщик копировал `life-os-ceramic-0.3.6.ico`. Проверка на этом ПК подтвердила: файл из свойства ярлыка отсутствовал. На текущем ПК исправлены ярлыки меню «Пуск» и рабочего стола; их исходные копии сохранены в `.artifacts/shortcuts-before-orvim`. Используемый значок совпадает по SHA-256 с ресурсом приложения.

В новом установщике ресурс и ярлыки используют одно имя `orvim-launcher.ico`, не зависящее от версии. При отсутствии отдельного ICO используется значок самого EXE. После установки отправляется уведомление оболочке Windows об изменении. Ярлык хранит путь и индекс значка, как описано в [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishelllinka-seticonlocation).

Для появления Orvim в меню «Пуск» и поиске используйте **установщик Windows**. Отдельный EXE предназначен для запуска без установки и не регистрирует ярлык автоматически.

## Обновление и данные

Идентификатор остаётся `local.lifeos.client`, база — `life-os.sqlite3`, формат — 31, схема SQLite — 3. Сохраняются совместимые ключи синхронизации, резервных копий и подключения. Папка старых автоматических копий Windows сохраняется в Документы/Life OS/backups. Переименование не переписывает названия пользовательских проектов и записей.

Для NSIS сохранены прежние ключи установки и удаления: `Software\lifeos\Life OS` и `Software\Microsoft\Windows\CurrentVersion\Uninstall\Life OS`. Отображаемое название — Orvim. Поэтому новая версия распознаёт прежнюю установку и использует её каталог. Ярлыки прежнего названия переносятся только при совпадении цели с установленным EXE. Используется [официальный шаблон Tauri CLI 2.11.5](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.11.5/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi) с фиксированными ключами; версия CLI закреплена. При её обновлении шаблон необходимо сверить с исходным.

Android использует прежний package ID и сертификат: устанавливайте APK поверх предыдущего приложения.

## Проверка

На текущем ПК проверены отсутствие прежнего файла значка, исправленные пути двух ярлыков, совпадение значка с ресурсом и наличие приложения в `Get-StartApps` с прежним AppID. Интерфейс самого поиска Windows визуально не проверялся. До установки нового выпуска текущий экземпляр называется Life OS.

Компиляция TypeScript, сборка Windows с NSIS и сборка Android завершились успешно. У EXE проверены ProductName `Orvim` и ProductVersion `0.4.6`; у APK — название `Orvim`, прежний package ID, версия `0.4.6` и versionCode `4006`. Подпись APK совпадает с 0.4.5, проверены схемы v2/v3 и выравнивание 16 КБ. Итоги, размеры файлов и SHA-256 записаны в `releases/0.4.6/build-info.json`.

Полный набор тестов в этой итерации не запускался; установка нового выпуска на этом ПК и физическом телефоне не выполнялась. Совместимость обновления проверена по конфигурации и собранному шаблону установщика, но фактическое обновление прежней установки остаётся непроверенным.
