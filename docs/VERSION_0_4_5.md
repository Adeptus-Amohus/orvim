# Life OS 0.4.5 — выбор расчёта целей

## Как пользоваться

В «Жизнь → Тренировки → + Цель» выберите упражнение и способ расчёта:

- **За один подход / За одно занятие.** Цель показывает последний выполненный результат. Например, цель 20 подтягиваний, последний подход 12 — 60%. Повторения разных занятий не складываются.
- **Всего за период.** Складываются результаты выполненных упражнений между выбранными датами. Например, 8 и 12 подтягиваний в двух занятиях дают 20 из 20 — 100%.

Способ можно менять через карточку цели → «Изменить цель». У каждого упражнения и каждой цели свой выбор; на одно упражнение можно поставить обе цели. Старые цели сохраняют прежний расчёт последнего результата.

Кнопка «В расписание» добавляет тренировку с нужным упражнением. Заполните план и повтор при необходимости. Галочка выполняет план, записывает результат и сразу обновляет связанные цели. Факт можно исправить прямо в строке без отдельного сохранения. Снятие галочки исключает результат из расчёта; повторная отметка учитывает его один раз.

## Подходы и начальное значение

Повторы вводятся за один подход. Для одинаковых подходов укажите их количество: 10 повторов × 3 подхода = 30 повторов в накопительной цели. В цели одного подхода это остаётся 10. Если подходы различаются, можно внести общее число повторов с количеством подходов 1; этот итог подходит для накопительной цели, для сравнения одного подхода нужна отдельная запись соответствующего результата.

Для километров и минут складываются результаты занятий. Килограммы — записанные рабочие веса; число подходов не умножает вес. Для цели рабочего веса обычно подходит режим «За один подход».

«Уже выполнено» — начальный накопленный результат. Он добавляется один раз. Изменение начального значения и способа расчёта сохраняет результаты тренировок. В истории накопительной цели виден вклад каждого занятия.

## Совместимость и проверка

Версия 0.4.5, формат документа 31, схема SQLite 3. Поле `calculation` необязательно; старые записи принимаются. Для одинакового расчёта целей при синхронизации обновите и телефон, и ПК до 0.4.5.

В отдельном демонстрационном пространстве Chrome пройдено создание двух целей одного упражнения, планирование двух занятий, отметки по плану, исправление факта, снятие галочки, изменение подходов, начального значения и способа расчёта. После повторного открытия результаты сохранились. Для 8 и 12 повторов карточки показали 60% за последний подход и 100% за период. На ширине 390 px документ помещается в экран. Пользовательская база приложения не изменялась.

Полный набор тестов и стресс-тесты в этой итерации не запускались. Физический телефон, часы и реальный импорт Health Connect не проверены. Результаты компиляции, упаковки и подписи фиксируются в `releases/0.4.5/build-info.json` после подготовки выпуска. APK использует прежний личный тестовый сертификат и устанавливается поверх предыдущей версии.

Успешно завершены компиляция TypeScript и Rust, Windows EXE / NSIS и Android ARM64 APK. Проверены подпись, совпадение сертификата с 0.4.4, версия 0.4.5 / Android versionCode 4005 и выравнивание APK 16 КБ.
