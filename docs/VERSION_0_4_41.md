# Orvim 0.4.41

- Нажатие на блок задачи или события в сетке виджета расписания открывает небольшое окно редактирования поверх рабочего стола.
- Можно изменить название, дату, время начала и длительность в минутах. Галочка в списке задач по-прежнему отдельно отмечает выполнение.
- Сохранение сразу обновляет виджет. При следующем открытии Orvim изменения переносятся в основную базу по ID; повторная обработка не создаёт дубли.
- Для связанных тренировок обновляются дата, время и длительность. Состав упражнений не меняется.
- Перетаскивание и двойной тап не требуются: обычное нажатие на блок открывает редактор, прокрутка остаётся прокруткой.

Сборка предназначена для локального тестирования. Android подписан прежним тестовым сертификатом; публикация в GitHub не выполняется.
