# Orvim 0.4.44

8 ноября 2026. Локальная Android-сборка для проверки виджета питания.

- Возвращено вертикальное расположение: название, крупные калории, цель и полоска прогресса.
- Надпись «Записать еду» заменена графическим плюсом справа по центру. Плюс открывает быстрое добавление еды.
- Размер питания остаётся 2 × 1; ниже можно разместить виджет мысли. Цвета следуют теме приложения.

После обновления откройте Orvim один раз для обновления виджетов. APK подписан прежним тестовым сертификатом. Windows-сборка в этом изменении не создавалась.
