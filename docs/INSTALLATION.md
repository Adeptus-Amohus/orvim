# Установка и обновление Orvim 0.4.46

[Публичный выпуск](https://github.com/Adeptus-Amohus/orvim/releases/tag/v0.4.46) доступен без аккаунта GitHub. В нём находятся APK, установщик EXE, документация, SHA-256 и лицензии. Исходники приложения хранятся отдельно; доступ к ним для установки не нужен.

## Android

Требования: Android 7.0/API 24 или новее, ARM64 (`arm64-v8a`), актуальный Android WebView. Для 32-битных ARM и x86 отдельной сборки нет. Health Connect требует поддерживаемой версии Android и собственных разрешений.

1. Скачайте [Orvim-0.4.46-Android-arm64.apk](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/Orvim-0.4.46-Android-arm64.apk).
2. Сверьте файл с [SHA256SUMS.txt](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/SHA256SUMS.txt).
3. Откройте APK через файловый менеджер; при необходимости самостоятельно разрешите установку этому источнику. Среда разработки и сервер Vite не нужны.
4. Откройте Orvim. При необходимости восстановите переносимую копию и проверьте записи после перезапуска.

Идентификатор `local.lifeos.client`, версия `0.4.46`, `versionCode 4046`. APK подписан постоянным release-ключом Orvim. Для следующих обычных обновлений сохраняются тот же идентификатор и сертификат, а versionCode увеличивается.

### Переход со старого тестового APK

У тестовых APK до 0.4.45 включительно другой сертификат. Android не установит 0.4.46 поверх них. Безопасный порядок:

1. В старом приложении откройте **Настройки → Данные → Копия с паролем**. Сохраните файл вне приватной папки приложения и второй экземпляр на другом носителе. Пароль храните отдельно.
2. **Проверьте восстановление** на отдельной установке/устройстве: записи, обложки и повторное открытие после перезапуска. Сохраните прежний APK. До этой проверки старое приложение не удаляйте.
3. После успешной проверки копии удалите старое тестовое приложение и установите release APK.
4. Восстановите копию с паролем, проверьте данные и повторно настройте подключения/виджеты.

Автоматические снимки с ключом устройства не заменяют переносимую копию: при удалении приложения его приватная база и ключ могут быть утрачены. CSV не является полной копией. Если восстановление проверить невозможно, сохраните старую установку до безопасного переноса.

## Windows

Требования: Windows 10/11 x64 и Microsoft Edge WebView2 Evergreen Runtime. Если runtime отсутствует, установщик загружает его с серверов Microsoft; для этого первого шага нужен интернет. Node.js, Rust, Java и Android SDK для работы не требуются.

1. Скачайте [Orvim-0.4.46-Windows-x64-setup.exe](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.46/Orvim-0.4.46-Windows-x64-setup.exe) и сравните SHA-256.
2. Перед обновлением создайте переносимую копию с паролем. Завершите Orvim через **Выход** в меню трея.
3. Запустите установщик. Для обновления используйте прежнюю папку; заранее удалять приложение или базу не требуется. Старые пути Life OS сохраняются для совместимости.
4. Откройте Orvim и проверьте записи после повторного запуска.

EXE **не подписан Authenticode**. Возможны предупреждения Windows/SmartScreen; отсутствие предупреждений не обещается. Подпись Android не является подписью EXE.

Удаление: **Параметры Windows → Приложения → Orvim → Удалить**. Не выбирайте очистку пользовательских данных, если они нужны; независимую копию храните отдельно.

## Проверки и ограничения

Установка, запуск, обновление/замена пакетов и сохранность данных проверены в доступных средах. Физический ARM64-телефон, все OEM-лаунчеры, API 24 на устройстве, чистая Windows без WebView2 и живые ИИ/Google/Notion/Health Connect не проверены этим выпуском. [Отчёт и происхождение сборки](RELEASE_0_4_46.md).

Публичное скачивание работает без авторизации. Автоматический подписанный канал обновлений приложения отдельно не включён; используйте ручное обновление из этого выпуска.
