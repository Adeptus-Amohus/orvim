# Проверка Orvim 0.4.26

- Проверка типов, сборка web, Clippy: пройдены.
- Нативные Rust-тесты: 54 прошли, 1 служебный тест пропущен.
- Общий набор npm run test:ui и 23 node-теста: пройдены.
- Браузер: 77 проверок нового чата, сохранения явного выбора контекста после перезагрузки, ограничения дат, длинных предложений, ошибки провайдера, сворачивания сна и трёх режимов фильтров финансов на ширинах 320/390/1280; дополнительно 69 проверок сна и фактического сохранения питания ИИ. Ответы провайдера и хранение в браузере подменены тестовыми.
- Эмулятор Android 16: обновление подписанного ARM64 APK с 0.4.25 на 0.4.26, сохранение тестовой записи сна, свёрнутая форма и список ночей, открытие нового окна ИИ и сохранение выбранного контекста после принудительной остановки и перезапуска. Тест проводился в новом профиле Android внутри read-only эмулятора; каталоги профиля подготовлены вручную из-за ошибки инициализации вторичного пользователя образа.
- Проверены версия, идентификатор, сертификат APK (совпадает с 0.4.25), выравнивание и соответствие JS/CSS внутри EXE и APK актуальной web-сборке. Файлы выпуска 0.4.25 не изменены.

Реальный телефон, живые ответы DeepSeek/OpenAI/Gemini, микрофон, показ уведомлений в назначенное время и интерфейс установщика Windows в этом этапе не проверялись. Уточнённая инструкция по приблизительной оценке еды не гарантирует поведение конкретной модели и точность пищевой ценности.
