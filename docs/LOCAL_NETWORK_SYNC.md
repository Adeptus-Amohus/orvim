# Синхронизация Life OS по общей сети

## Подключение

1. Установите Orvim 0.4.12 на ПК и телефон. Подключите устройства к одной домашней сети Wi-Fi. ПК может быть подключён кабелем к тому же роутеру. Начиная с 0.4.11 используется протокол обмена 3; обе стороны должны поддерживать правила задач без даты и финансов по счетам. В 0.4.12 этот протокол сохранён.
2. На ПК откройте **Настройки → Данные → Синхронизация по сети** и нажмите **Создать подключение на ПК**.
3. Если Windows спросит о доступе к сети, разрешите Life OS в **частной сети**.
4. На телефоне откройте тот же раздел. Введите показанный адрес ПК, восьмизначный код и название телефона. Нажмите **Подключить**.
5. Оставьте Life OS открытым на обоих устройствах. Изменения передаются автоматически после сохранения и примерно раз в 20 секунд. Можно нажать **Синхронизировать сейчас**.

Код действует 5 минут и используется один раз. Для второго телефона нажмите **Добавить устройство**: появится новый код. ПК запоминает подключение и запускает его при следующем открытии приложения. Разрешено до восьми устройств. При вводе текста и открытом редакторе получение изменений откладывается, чтобы сохранить черновик.

## Что передаётся

Задачи, события расписания, проекты, мысли, записи сна, питания, воды, самочувствия, тренировок и финансов; цели, шаблоны, сохранённые блюда и упражнения; коллекции базы данных, их статусы, оценки, изображения, файлы и ссылки на материалы. Дневные цели питания и воды, валюта и финансовые категории тоже общие.

В 0.4.10 также передаются финансовые счета и бюджеты категорий, результаты отдельных подходов и метки самочувствия. Шаблоны финансовых операций и таймер отдыха остаются местными настройками. Синхронизация идёт по записям; рабочий файл SQLite целиком не копируется.

Тема, язык, шрифт, уведомления и настройки подключений остаются отдельными для каждого устройства. API ключи не передаются.

Записи объединяются по постоянным идентификаторам. Одновременные правки разных полей объединяются. Если оба устройства изменили одно поле, раздел **Одновременные изменения** сохраняет обе версии и предлагает выбрать. Удаление передаётся как отдельное изменение. Одновременное удаление и редактирование допускает восстановление записи с сохранёнными правками.

Перед первым обменом каждого подключения создаётся JSON копия в папке данных приложения: `local-sync/sync-backups`. Это отдельная резервная копия, которую можно восстановить через обычный импорт JSON. Синхронизация не заменяет регулярное резервное копирование.

## Когда связи нет

Данные продолжают сохраняться на устройстве. Обмен повторяется при возвращении в приложение. На Android обмен работает, пока приложение на переднем плане; фоновый сервис не используется. ПК должен быть включён, Life OS должен работать. Интернет не требуется.

Если ПК получил другой адрес от роутера, на телефоне откройте **Изменить адрес ПК** и сохраните новый адрес из настроек ПК. Повторный код не нужен.

Если соединения нет, проверьте одну сеть, частный профиль и разрешение брандмауэра Windows. Гостевые Wi-Fi сети могут запрещать связь между устройствами. Используется TCP порт **42673**; переадресация портов в интернет не требуется. Доступны локальные IPv4 адреса, включая личную точку доступа телефона; IPv6 и публичные адреса не поддерживаются в этой версии.

**Отключить синхронизацию** прекращает обмен, сохраняя данные. На ПК **Отозвать доступ** отключает конкретное устройство: для возвращения нужен новый код.

## Техническая проверка

Сопряжение использует SPAKE2, обмен — XChaCha20-Poly1305 с отдельным подтверждением каждого сеанса. Ключи хранятся средствами Windows DPAPI / Android Keystore. Журнал изменений хранится отдельно; рабочий SQLite файл не передаётся и не заменяется по сети.

Проверены реальное сопряжение и TCP обмен на ПК, неверный код, одноразовость, отзыв доступа, повреждённый шифротекст, объединение правок, удаления, ссылки и обложки, повторные запросы и 10 000 задач. Связь с физическим Android телефоном через домашний роутер пока не проверена.
