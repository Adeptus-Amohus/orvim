# Orvim 0.4.48

English | [Русский](0.4.48.md)

**Check GitHub** now checks the public Orvim repository. If a release has no signed manifest, the app checks the available version and opens the release page. In-app download and installation are offered for packages listed in a verified manifest. The database format must also be compatible.

## Updating from 0.4.46 or 0.4.47

These releases use the previous update URLs. If the update check returns a 404, create a backup, download the 0.4.48 package for your device, and verify its SHA-256 checksum in `SHA256SUMS.txt`.

- **Android:** Open `Orvim-0.4.48-Android-arm64.apk` and confirm the update over the installed app. These three releases use the same app ID (`local.lifeos.client`) and Android signing certificate. Earlier test APKs with a different certificate require a [verified backup and reinstall](../INSTALLATION.en.md#migrating-from-an-older-test-apk).
- **Windows:** Close Orvim through **Exit** in the system tray and run `Orvim-0.4.48-Windows-x64-setup.exe`. Open the app afterward to check your records. Windows may warn that the publisher is unknown because the EXE is unsigned.
