# Orvim 0.4.47

14 ноября 2026 года.

- Поля ввода и редактирования мыслей получили отступы, читаемую рамку и перенос длинного текста. Когда клавиатура уменьшает окно Android, страницу можно прокрутить до кнопки сохранения.
- В настройках личного дня снова отображается значок рассвета.
- Уточнены инструкции обновления и браузерные проверки меню и форм.

[Android ARM64 APK](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.47/Orvim-0.4.47-Android-arm64.apk) и [Windows x64 EXE](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.47/Orvim-0.4.47-Windows-x64-setup.exe).
[Установка и обновление](../INSTALLATION.md) · [SHA-256](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.47/SHA256SUMS.txt).

APK рассчитан на Android 7.0 и новее на ARM64. Идентификатор приложения `local.lifeos.client`, код версии 4047. Постоянный сертификат совпадает с сертификатом 0.4.46. Для перехода со старых тестовых APK до 0.4.45 сначала создайте переносимую копию с паролем и проверьте восстановление.

Установщик рассчитан на Windows 10/11 x64 с WebView2 Evergreen. EXE не подписан Authenticode. Обновление выполняется вручную.

Исходники сборки зафиксированы в [коммите 6c9667e](https://github.com/Adeptus-Amohus/orvim/commit/6c9667ea46be3e953f0fc891170d350443c12835). Тег [v0.4.47](https://github.com/Adeptus-Amohus/orvim/releases/tag/v0.4.47) указывает на этот коммит. Команды сборки и подписи приведены в [порядке выпуска](../RELEASING.md).

В Windows проверены обновление с 0.4.46, повторная установка и сохранение данных в отдельном профиле с WebView2. APK проверен на эмуляторе API 36 с трансляцией ARM64 в профиле, ранее обновлённом с 0.4.46. Проверки на физическом телефоне для этого APK, Windows без WebView2 и все внешние сервисы остаются вне подтверждённого охвата. [Отчёт проверок](https://github.com/Adeptus-Amohus/orvim/releases/download/v0.4.47/Verification.md).
