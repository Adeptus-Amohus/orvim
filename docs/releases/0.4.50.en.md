# Orvim 0.4.50

## Updates

- Release notes display headings and lists.
- Download and install verifies the downloaded package and opens the system installer.
- Fixed an Android error that prevented Orvim from opening the downloaded APK.

## Nutrition and database

- The time picker's Choose button saves the meal time immediately and recalculates its personal day.
- Project materials has its own database tab alongside Collections and Archive.

## Updating from Android 0.4.49

Download the APK from this release and install it over your current version. The application ID and release signing certificate are unchanged. Confirm the update in Android's system installer.
