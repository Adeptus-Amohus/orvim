# Orvim 0.4.46

Первый выпуск с постоянной Android release-подписью и установщиком Windows x64. Дата подготовки: 10 ноября 2026. Окончательный исходный commit приложения — `d632f6b0d536968b1564fcdd0abfe6c4d6b95d55`, зафиксированный первоначальным тегом приватного life-os и build-info.json. Старый публичный тег Orvim v0.4.46 относится к материалам распространения и сайту; он не переносится. Снимок кода в основном репозитории обозначается отдельно как source-v0.4.46. [Происхождение и история](../REPOSITORY.md).

## Изменения, вошедшие после сохранённого состояния 0.4.23

- Шифрование локальной базы и автоматических копий; переносимые копии с паролем и восстановление при ошибке открытия. Ключ устройства защищается DPAPI Windows / Android Keystore.
- Передача данных между устройствами через LAN и файл, проверка импортируемых изменений и конфликтов; прежний WebDAV-интерфейс удалён.
- Уточнения личного дня, сна, питания, веса, самочувствия и статистики; безопасный предпросмотр импорта.
- Русский/английский интерфейс, пользовательские шрифты, исправления мобильных форм, меню и взаимодействий. Встроенная диктовка убрана; можно пользоваться вводом клавиатуры ОС.
- Android: виджеты расписания/задач, записи мысли и компактного питания 2 × 1; отдельные формы быстрого ввода и темы виджетов.
- Windows: работа в трее, настройка закрытия окна и увеличенный отдельный ресурс значка трея.
- Разделённая загрузка интерфейса и оптимизации отрисовки; вращающийся знак и индикатор запуска с учётом уменьшения движения.
- Чат ИИ отправляет сообщение с вручную выбранным контекстом без промежуточной автоматической панели. Применение предложенных изменений по-прежнему требует подтверждения.
- 0.4.46: согласованы версии пакетов; добавлены воспроизводимая подпись APK с проверкой постоянного сертификата, инструкции установки/перехода, лицензии и комплект исходников desugar_jdk_libs 2.1.5.

Это перечень изменений исходников, а не обещание проверки всех внешних сервисов. Исторические подробности: `docs/VERSION_0_4_24.md` — `docs/VERSION_0_4_45.md`. Публичных предыдущих GitHub Releases при подготовке не было.

## Установка

[Полная инструкция и требования](../INSTALLATION.md). Android: API 24+, ARM64, `local.lifeos.client`, `versionCode 4046`. Windows: Windows 10/11 x64, WebView2. APK подписан постоянным ключом Orvim; Windows EXE не подписан Authenticode.

**С тестового Android APK нельзя обновиться поверх установки:** сертификат изменился по решению владельца. Сначала создайте и проверьте внешнюю копию с паролем. Удаление тестового приложения допустимо только после проверки восстановления. Для будущих release APK ключ сохраняется.

Результаты установки, запуска, обновления и тестов, ограничения и SHA-256 фиксируются в `Verification.md`, `build-info.json` и `SHA256SUMS.txt` выпуска. Недоступные проверки не считаются пройденными. Файлы и пользовательские инструкции доступны без авторизации в [публичном выпуске Orvim](https://github.com/Adeptus-Amohus/orvim/releases/tag/v0.4.46); исходники находятся в основном Orvim, автоматический канал обновлений не включён.

## Сборка из тега

Нужны Node.js 22.12+ (использован 24), Rust stable MSVC, C++ Build Tools/Windows SDK, Perl для vendored OpenSSL; для Android также JDK 21, SDK 36, Build Tools 35/36, NDK 30.0.16248370 и Rust target `aarch64-linux-android`.

```powershell
git checkout source-v0.4.46
npm ci
npm run licenses:check
npm run test:ui
npm run rust:fmt
npm run rust:check
npm run rust:lint
npm run rust:test
npm run tauri -- build --bundles nsis --ci
npm run android:build -- --apk --target aarch64 --ci
```

`build` включает typecheck. Для Android кросс-компиляция OpenSSL на Windows требует Unix-совместимый Perl (например, Git for Windows/MSYS) и его штатные модули, для MSVC — Windows Perl и C++ Build Tools. Не заменяйте библиотеки готовыми файлами от прежней версии. Локальные временные пути инструментов не являются зависимостью исходников. Зависимости закреплены lockfiles; точные версии среды записываются в `build-info.json`. Воспроизводимость означает команды и зафиксированные исходники; побайтовая идентичность разных сред не обещается.

На Windows используйте подготовленный скрипт вместо прямой Android-команды: он добавляет NDK Make, задаёт пути clang/ar без обратных слешей и API 24. `-PerlLibrary` нужен только если вашей установке Unix Perl требуются дополнительные модули; это путь к установленным модулям, не обязательная папка в исходниках.

```powershell
./scripts/build-android-release.ps1 -PerlBin 'C:/Program Files/Git/usr/bin'
```

После release-сборки задайте безопасным способом переменные `ORVIM_ANDROID_KEYSTORE`, `ORVIM_ANDROID_KEY_ALIAS`, `ORVIM_ANDROID_STORE_PASSWORD`, `ORVIM_ANDROID_KEY_PASSWORD`, а также `JAVA_HOME` и `ANDROID_HOME`. Пароли не вводите буквальным текстом в команды/логи. Выполните:

```powershell
./scripts/sign-android-release.ps1 -UnsignedApk src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release-unsigned.apk -OutputApk Orvim-0.4.46-Android-arm64.apk
Get-FileHash -Algorithm SHA256 Orvim-0.4.46-Android-arm64.apk
Get-FileHash -Algorithm SHA256 src-tauri/target/release/bundle/nsis/Orvim_0.4.46_x64-setup.exe
```

Хранилище ключа и пароли остаются вне Git. Точный постоянный сертификат проверяется скриптом. [Подпись и резервирование ключа](../ANDROID_SIGNING.md), [процесс выпуска](../RELEASING.md).
