# Orvim 0.4.33

2 ноября 2026.

## Жизнь и тренировки

- Вернулась круглая форма самочувствия в центре жизни. Общий стиль кнопок больше не перекрывает формы круглых элементов. Карточки жизни получили мягкие углы.
- Одна необязательная оценка сложности на завершённое занятие: очень легко, легко, нормально, тяжело, очень тяжело. Оценку можно изменить или убрать.
- Оценка сохраняется на уровне тренировки и не меняет результаты подходов. Ввод оценки каждого упражнения убран. Прежние индивидуальные оценки сохранены в данных для совместимости, но не выдаются за общую оценку занятия.

## Мысли

- Список прокручивается внутри своей области. Заголовок «Мысли», дата, поиск и форма новой записи остаются на месте.
- Следующие записи автоматически подгружаются при прокрутке. Начальные 60 записей — размер первой порции, а не ограничение хранилища.
- Поиск работает по всей коллекции, включая записи, которые ещё не показаны в списке. Карточки имеют полную округлую рамку.

## Настройки

- «Мой день» теперь находится отдельным заметным пунктом в «Настройки → Данные». На карточке видно текущее начало дня.

## Импорт

- JSON API: принимается массив в корне, `items`, `results`, `data` и объект с коллекцией внутри `data`. ID `0` считается допустимым. Строка `"false"` больше не превращает задачу в выполненную.
- Notion: учитывается стандартный статус Done/Completed/Готово/Выполнено/Завершено, а не только checkbox. Разные ссылки на один источник не создают дубликаты уже известных страниц.
- Удаление записи в Notion учитывается также для проектов, мыслей и базы данных. Изменённые вручную записи сохраняются и учитываются как конфликт.
- Ссылка на Notion с завершающим слешем корректно распознаётся.
- Проверены предпросмотр, применение, повторный импорт, ошибки доступа и оба пути календаря: Google API на ПК и системный календарь Android.

Для Notion нужны ключ интеграции и доступ этой интеграции к нужной базе. В подключениях раскройте «Источник и доступ» и «Что перенести». Произвольный JSON API должен вернуть поддерживаемый список записей со стабильными ID; приложение не может автоматически понять любой формат стороннего сервиса.

Предыдущая сборка 0.4.32 сохранена отдельно. Выпуск подготовлен локально, без публикации на GitHub.
