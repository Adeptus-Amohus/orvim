## Проверки

- `npm run test:ui`: полный существующий контур DOM, моделей и сервисов плюс 19 новых проверок взаимодействий; успешно.
- `npm run test:interaction-browser`: 73 проверки в изолированном Chromium, без необработанных ошибок. Артефакты: `.artifacts/interaction-audit/report.json` и снимки экрана.
- `npm run build`: проверка TypeScript и production-сборка Vite; успешно.
- `npm run rust:check`: успешно.
- `:app:compileUniversalReleaseKotlin`: успешно. Использованы локальные Android SDK/JDK и Gradle cache в `.artifacts`.
- Стресс-проверки включают 300 проектов, 100 задач и 100 пересекающихся событий. Проверки используют искусственные данные.

## Ограничения проверки

Установленное приложение на физическом Windows-компьютере и реальный Android-телефон не запускались. Проверка браузерных размеров, имитация клавиатуры и компиляция Kotlin не подтверждают поведение настоящей IME, системного жеста, установщика и WebView конкретной модели телефона. Фактическая синхронизация двух устройств также не проверялась в этой работе.

Реальные пользовательские базы не открывались, не очищались и не восстанавливались. Существующие данные и несвязанные изменения сохранены. Предыдущие файлы версии 0.4.11 остаются отдельно.
