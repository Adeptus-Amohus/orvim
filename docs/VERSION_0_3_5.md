# Life OS 0.3.5

## Уведомления

- Самочувствие: Short Compact, короткий звук. Напоминание раз в четыре часа после отметки.
- Расписание: Velvet Warm. Уведомление за пять минут до события; задача получает напоминание, когда для неё назначены дата и время.
- Настройки → Уведомления: общий выключатель, отдельные выключатели самочувствия и расписания, возможность оставить уведомления без звука. Есть кнопки прослушивания.
- Выключатели сохраняются между запусками и входят в резервную копию. Старый общий выключатель сохраняет своё значение при обновлении.
- Для Android выделены отдельные каналы для каждого вида уведомлений со звуком и без него. Для Windows используются локальные звуковые файлы уведомлений.
- Звуки прокрутки и сохранения самочувствия, случайные фразы и подарочные окна отсутствуют.

## Проекты и база данных

- Материалы внутри каждого проекта: ссылки, изображения, заметки, файлы и ссылки на записи базы данных. Внешние ссылки можно открыть сразу; материал можно изменить.
- У коллекций свои статусы, жанры, необязательная оценка по шкале до 5 или 10 с половинными шагами. Коллекции можно переименовать, удалить и восстановить через отмену.
- Основное действие проекта — создание задачи. Изменение и удаление проекта находятся в меню действий; удаление требует подтверждения.

## Сборка

- Одинаковый керамический рисунок и белый фон в значках Windows и Android. Исправлен оставшийся тёмный фон обычных и адаптивных Android-значков. Внутри приложения сохраняется отдельный упрощённый знак с оттенком темы.
- Исправлено кодирование PNG Windows-значков: RGBA с непрозрачным фоном, совместимое с Android-сборкой Tauri.
- Версия APK: 0.3.5, код 3005, ARM64, Android 7+. Подпись тем же тестовым сертификатом, что у 0.3.4; проверяется выравнивание на 16 КБ.
- Windows: установщик x64 и отдельный EXE. Для отдельного EXE нужен WebView2.
- Обновление использует существующее локальное хранилище. Синхронизации ПК и телефона в этой версии нет.

## Проверка

- 368 проверок интерфейса, преобразования данных, сохранения, резервных копий, коллекций и уведомлений.
- 15 тестов Rust: миграции, SQLite, атомарность операций, сохранение обложек и материалов, защищённое хранилище Windows; стресс-тест на 10 000 задач с повторным открытием базы.
- Проверка типов TypeScript, Rust fmt и Clippy, production-сборка интерфейса, Windows NSIS, Android Kotlin/Java/R8 и lintVital.
- Реальный Chrome: основные действия всех разделов, темы, шрифты, поиск, резервная копия, повторный запуск; размеры экрана 320–1920 пикселей, включая короткое горизонтальное окно.
- Стресс-тест браузера: 1000 задач и 300 одновременных событий, ограниченная прокрутка задач, доступ к последней задаче и событию. Пересекающиеся события объединяются в список, сохраняя возможность редактировать каждое.
- Отдельно проверены настройки уведомлений, прослушивание двух WAV, сохранение выключателей, восстановление копии и мобильная раскладка.

Фактические результаты и контрольные суммы находятся рядом с файлами в `releases/0.3.5/build-info.json` и `VERIFICATION.md`.

Физический телефон не подключён. Доставка и звук системных уведомлений на устройствах, экранная клавиатура Android, ограничения фоновой работы, обновление кэша значка Windows и подключения к реальным аккаунтам требуют проверки после установки. Браузерные проверки не заменяют эти проверки.
