# Проверка Orvim 0.4.41

7 ноября 2026. Локальные Android ARM64 и Windows x64 сборки.

- TypeScript и production frontend build прошли.
- `tests/browser-widget-journal.cjs` прошёл: создание записей, КБЖУ, выполнение, перенос изменений в существующую задачу по ID, повторный импорт без дублей, сохранение квитанций после перезапуска. Проверены новая дата, время и длительность.
- Android 16 API 36, read-only AVD LifeOS_API_36, отдельный пользователь 10: 7 нативных тестов прошли за 46,408 с. Включают прямое открытие редактора и сохранение названия/длительности, журнал, еду, размеры, темы и прокрутку виджетов.
- Отдельный тест реального нажатия на блок в AppWidgetHost первоначально обнаружил отсутствие вызова клика во вложенной разметке. После добавления контейнера вокруг текста события тест прошёл за 5,668 с: блок открывает редактор через PendingIntent, поля заполнены данными записи, изменение длительности сохраняется в журнал. Снимок: `.artifacts/widgets-qa/native-final-0441/schedule-editor-real-tap.png`.
- Финальный APK пересобран после изменения разметки. Проверены сертификат прежней версии, версия 0.4.41 / 4041, ARM64, 16 KB ZIP alignment, совпадение native library и встроенных frontend assets с текущими исходниками.
- Windows EXE скомпилирован; установщик NSIS создан успешно. Проверены ProductVersion 0.4.41 и ProductName Orvim. Для NSIS применён локальный кэш в target/.tauri. Существующая установленная программа и пользовательская база на ПК не изменялись.

Материалы: `.artifacts/widgets-qa/native-0441-seven.txt`, `tap-0441.txt`, `release-0441-final.txt`; `.artifacts/build-0441-final-refresh.log`, `.artifacts/windows-0441.log`, `.artifacts/windows-0441-bundle-final.log`; `releases/0.4.41/build-info.json`.

Физический телефон пользователя и установка EXE не проверялись в этой итерации. Новые записи и изменения виджетов сразу хранятся в зашифрованном журнале; в основную базу и её синхронизацию они переносятся при следующем открытии Orvim.
