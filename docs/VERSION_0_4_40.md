# Orvim 0.4.40 — оформление виджетов и кнопка сна

Локальный Android APK для тестирования, без публикации.

- Расписание, питание и запись мысли следуют палитре Orvim: солнце, хвоя, алый и зимний. Светлый/тёмный режим из приложения имеет приоритет над системным; режим «Системный» использует оформление Android. Настройки передаются виджетам при сохранении приложения.
- На Android 12+ поддерживается также собственный цвет. На Android 7–11 для собственного цвета используются стандартные фоны солнечной палитры; четыре встроенные темы поддерживаются полностью.
- Питание стало компактной карточкой высотой 132 dp. Растягивание отключено; даже если лаунчер оставил старый высокий контейнер, белая карточка больше не заполняет его целиком.
- Запись мысли — полоса высотой 48 dp с полупрозрачной подложкой и рамкой. Она растягивается по горизонтали, текст остаётся контрастным на обоях.
- Окна ручной записи тоже используют оформление приложения; убраны стандартные тени кнопок.
- На главной запись сна заменена кнопкой с луной справа от времени. Её появление и скрытие не меняет размеры карточек времени, самочувствия и остальных блоков.

После установки откройте Orvim один раз. Для новых ограничений размера питания может понадобиться удалить старый виджет питания и добавить его снова: размеры ячеек хранит лаунчер.

Техническая основа: [Android RemoteViews](https://developer.android.com/reference/android/widget/RemoteViews), стандартные векторные фоны и нативные текстовые элементы. Расписание не преобразуется в растягиваемую картинку.
