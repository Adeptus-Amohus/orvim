# Life OS 0.3.3

- Значок Windows заменён упрощённым керамическим B, как в шапке мобильного интерфейса. Нативный значок Android сохраняется.
- Главное меню: Главная → Жизнь → Мысли → Проекты → База данных → Архив. Настройки остаются отдельно.
- Проекты можно изменять по названию или кнопке карандаша, удалять кнопкой корзины или из окна изменения. Перед удалением показано пояснение. Задачи и события переходят в «Личное»; удаление можно отменить.
- Мысли самостоятельны: нет выбора проекта, фильтра по проектам или вкладки мыслей в проекте. Существующие тексты и даты сохраняются.
- Для финансов используется значок банкноты. Круговая диаграмма показывает расходы выбранного месяца и валюты, суммы и доли категорий. Нажатие на категорию фильтрует операции; «Все операции» снимает фильтр. Доходы не включаются в распределение расходов.
- Категория «Питание» отображается как «Еда» и объединяется с ней в диаграмме. Можно добавлять свои категории.

Сборки содержат все текущие разделы рабочего дерева. Компиляция и типизация входят в сборку; дополнительные тесты поведения в этой итерации не запускались. Физический телефон не подключён.

APK подписывается тем же сертификатом, что 0.3.2. Формат базы не меняется. Файлы, подпись и контрольные суммы находятся в `releases/0.3.3`.
