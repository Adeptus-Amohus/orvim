# Orvim 0.4.26

- ИИ: одна кнопка «Данные для ИИ» вместо трёх дублирующих входов. Явно выбранный контекст запоминается между открытиями и перезапусками. «Убрать всё» и очистка переписки отзывают выбор.
- Пояснения о передаче данных, просмотр запроса и ограничение дат перенесены внутрь выбора контекста. Переписка и предложения занимают доступную высоту; длинные списки не перекрывают поле ввода. Убрано повторение технических полей в предложениях питания.
- ИИ: при понятном продукте и порции разрешена приблизительная оценка калорий и БЖУ с соответствующей пометкой. Для записи еды не нужно указывать суточную норму калорий или основной обмен. Поведение конкретной внешней модели может отличаться; фактическая пищевая ценность требует проверки.
- Сон: заполненная форма сворачивается в строку с датой и длительностью; раскрывается для изменения. Список записей под картой месяца свёрнут отдельно.
- Финансы: ровные фильтры периода, валюты и даты, отдельная строка месяца или диапазона дат на телефоне; сохранены округлые элементы выбора.
- Сохранены шифрование базы, защищённые копии, трёхразовые напоминания и проверка фактического сохранения предложений ИИ.
