# Orvim 0.4.30

## Личный день и добровольный учёт

Откройте **Жизнь → Мой учёт**. Все новые показатели включаются по желанию. Отключение скрывает интерфейс и сохраняет историю.

- **Мой день:** задайте начало дня, например 22:00. Питание, вода, самочувствие, упражнения, цели и отчёты группируются от этого времени до того же времени следующей даты. В расписании сохраняются настоящие календарные даты и время. Старые записи без времени сохраняют свою дату; время для них не выдумывается.
- **Шаги:** Health Connect запрашивается по границам личного дня. После смены начала дня обновите данные в «Настройки → Подключения → Телефон и часы». Старые автоматические итоги с другой границей не выдаются за пересчитанные. Ручные дневные записи сохраняют указанную дату. Новых разрешений телефона не требуется.
- **Сложность упражнения:** после выполнения раскройте «Оценить сложность · необязательно». Пять вариантов от «Очень легко» до «Очень тяжело». Оценку можно убрать; пропуск оценки ничего не блокирует и не меняет результат упражнения.
- **Питание:** отдельные переключатели воды, калорий, БЖУ и витаминов/минералов. Старые значения остаются в истории. В новых ручных записях выключенные пищевые показатели не запрашиваются.
- **Витамины и минералы:** свои названия, единицы, количества и необязательная личная цель. График показывает записанное количество относительно вашей цели. Разные единицы не складываются. Рекомендаций по дозировкам нет.
- **Вес:** запись в килограммах, исправление и удаление записей, график за месяц, три месяца, год или всё время. Для графика используется последняя запись каждого дня; пропущенные дни не заполняются вымышленными значениями.
- **Болезнь:** период с датой начала и необязательной датой выздоровления. Кнопка «Выздоровел» завершает текущий период. Пропущенные тренировки исключаются из знаменателя выполнения плана; шаги за болезнь остаются в фактическом итоге и учитываются отдельно от среднего вне болезни. Это не превращает пропущенное занятие в выполненное.
- **ИИ:** выбранный контекст «Жизнь» включает новые показатели, границу личного дня и периоды болезни. Без выбора этих источников записи не передаются провайдеру. Подтверждение изменений сохранено.

## Совместимость и перенос

Формат рабочего пространства — **32**, протокол локальной синхронизации — **4**, формат нового файла переноса — **2**. Обновите Orvim на обоих устройствах перед синхронизацией. Старые резервные копии и файлы переноса версии 1 читаются; старое приложение не должно открывать новую базу.

Включены подготовленные ранее исправления: перенос зашифрованного файла по USB с сравнением конфликтов, понятные названия настроек при сравнении, исправление добавления еды после синхронизации неоценённых записей базы данных, встроенный QR-сканер Android и диагностика правил брандмауэра Windows. USB-перенос использует файл, который копируется через Проводник; это не автоматическое соединение по кабелю.

Релиз подготовлен локально. Публикация на GitHub не выполнялась. Перед обновлением сохраняйте резервную копию штатной кнопкой приложения.

Техническое основание пересчёта шагов: [официальная документация Health Connect](https://developer.android.com/health-and-fitness/health-connect/aggregate-data) — периодическая агрегация с границами LocalDateTime.
