# Проверка Orvim 0.4.44

8 ноября 2026. Изменение Android-виджета питания; Windows не пересобирался.

- TypeScript, Vite production build, Rust ARM64, Android release lint и Gradle release/debug/instrumentation сборки прошли.
- Android 16 / API 36, read-only AVD, отдельный пользователь 10: `compactFoodAndThoughtFitTwoRows` прошёл за 11,227 с. Питание и мысль размещены в AppWidgetHost по 156 × 72 dp каждое. Проверены размер 2 × 1, отсутствие изменения размеров питания, полная видимость элементов, последовательность название → калории → цель → прогресс, отсутствие пересечения с плюсом и центрирование плюса с допуском 1 px. Нажатие плюса открыло быстрое добавление еды.
- Снимок `food-and-thought-one-row-each.png` просмотрен: значения 858 / 2600 полностью видны, большой текст не зажат соседней целью, плюс выровнен. Белая подложка общего тестового окна вокруг двух виджетов не является областью питания.
- Два первых запуска остановились на привязке провайдера до измерения интерфейса: новый профиль эмулятора не обновил список AppWidget-провайдеров после установки. После обновления списка компонентов тест прошёл с тем же APK. Это ограничение подготовки тестового профиля; физический лаунчер в этом прогоне не проверялся.
- Итоговый подписанный APK установлен отдельно от debug-сборки. Проверка RemoteViews в framework и AppCompat хостах: `OK: 6 packaged widget hosts`.
- Подпись совпадает с прежним тестовым сертификатом; проверены идентификатор приложения, версия 0.4.44 / 4044, ARM64, 16 KB ZIP alignment, совпадение native library и текущих frontend assets. APK 0.4.43 сохранил прежний SHA-256.

Материалы: `.artifacts/build-0444-final.log`, `.artifacts/widgets-qa/native-0444-final.txt`, `.artifacts/widgets-qa/native-final-0444/`, `.artifacts/widgets-qa/release-0444-final.txt`, `releases/0.4.44/build-info.json`.

Физический телефон пользователя не проверялся. Сборка локальная, публикация не выполнялась.
