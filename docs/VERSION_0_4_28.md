# Orvim 0.4.28

- Упрощён раздел «Настройки → Данные»: единые заголовки с иконками, краткие подсказки без дублирования содержимого.
- В синхронизации показаны статус, последнее время обмена, подключённые устройства и два основных действия. Адрес и идентификатор ПК спрятаны в «Параметры подключения», инструкция раскрывается отдельно. Истёкший код и QR-код не занимают место; новый код выдаётся кнопкой «Добавить устройство».
- Копии и экспорт оформлены строками: защищённая копия, восстановление, CSV и внутренняя история. Открытый JSON и подробная политика автоматических снимков находятся в дополнительных разделах. Подтверждения восстановления и удаления данных сохранены.
- Исправлен конфликт идентификаторов при одинаковых названиях проектов, повторяющихся метках задач или старых совпадающих псевдонимах обмена. Записи сохраняются отдельно с устойчивыми идентификаторами; явные связи задач с проектами имеют приоритет перед совпадением названия.
- Изменения проверены в светлой и тёмной темах на узком экране и ПК. APK и Windows-пакеты предназначены для личной проверки. Выпуски в интернете не публиковались.
