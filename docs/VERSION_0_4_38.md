# Orvim 0.4.38 — самостоятельные действия виджетов

Локальный тестовый APK Android ARM64. Подпись остаётся прежней, обновление устанавливается поверх 0.4.37. Windows-сборки и публичной публикации нет.

После установки **удалите старые виджеты и добавьте заново**: изменились размер виджета мысли и структура расписания. Android-лаунчер может сохранять прежнюю сетку размещения при обновлении.

## Изменения

- Расписание теперь состоит из нативных прокручиваемых строк 00:00–23:00. Шрифты и блоки не растягиваются картинкой. Высота виджета меняет число видимых часов. «Сейчас» возвращает прокрутку к текущему времени. Список задач тоже прокручивается.
- Галочка задачи сохраняет изменение в фоне, не открывая главный экран Orvim.
- «+ Задача» и «+ Мысль» показывают небольшое окно над домашним экраном. В нём можно написать текст и добавить запись. У задачи можно выбрать дату и время.
- Виджет мысли стал компактной прозрачной плашкой с тонкой рамкой, значком Orvim и текстом; начальный размер — приблизительно 2 × 1, в зависимости от сетки лаунчера.
- В питании «+ Записать еду» открывает небольшую форму с названием и калориями. Калории проверяются: 0–10 000 на запись, без букв и отрицательных значений.
- В этой же форме есть «Оценить с ИИ». Используются выбранные в Orvim провайдер и модель, а ключ читается из защищённого хранилища Android. Поддерживаются OpenAI, DeepSeek и Gemini. Отправляется только описание еды; модель возвращает продукты и калории, без произвольных команд изменения базы. Перед добавлением показываются приблизительные значения. При ошибке можно заполнить вручную.
- Учёт питания учитывает начало личного дня. При полном удалении данных очищаются также кэш и ожидающие записи виджетов.

## Сохранение

Для этих действий не запускается MainActivity или WebView Orvim. Используются отдельное нативное окно и фоновый обработчик.

Записи надёжно сохраняются в отдельном зашифрованном журнале на устройстве и сразу учитываются в отображении виджетов. При следующем открытии Orvim они переносятся в основную базу; после подтверждённого сохранения журнал очищается. Квитанции переноса защищают от дублей после перезапуска или сбоя. Пока приложение закрыто, это локальные ожидающие записи: они ещё не входят в резервные копии и синхронизацию основной базы.

Журнал и проекция для виджетов защищены AES-GCM с ключом Android Keystore. Тексты мыслей и ключи API не передаются лаунчеру в проекции виджетов. На домашнем экране остаются видимыми названия задач и калории — это содержание выбранных пользователем виджетов.

Основа прокрутки: [Android collection widgets](https://developer.android.com/develop/ui/views/appwidgets/collections).
