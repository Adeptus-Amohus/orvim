# Закрытие в трей Windows

Изменение подготовлено в исходниках после 0.4.36; установщики с ним пока не собраны.

- По умолчанию крестик окна сохраняет данные и скрывает Orvim в системный трей.
- Щелчок по значку открывает окно. Правый щелчок показывает «Открыть Orvim» и «Выйти».
- «Выйти» сохраняет изменения и завершает приложение. Повторный запуск скрытого Orvim возвращает существующее окно.
- В **Настройки → Оформление → Сворачивать в трей при закрытии** можно отключить это поведение. Тогда крестик завершает приложение после сохранения.
- Настройка относится только к текущему ПК. Она хранится в `desktop-preferences.json` в каталоге данных приложения, вне базы, резервных копий и синхронизации.
- Если значок не удалось создать, закрытие завершает приложение; скрытого окна без доступного трея не остаётся.
- Ошибка сохранения оставляет окно открытым. В трее приложение продолжает работать и расходовать ресурсы; это не автозапуск Windows.
- На Android переключатель отсутствует. Варианты Android-виджетов пока являются макетами и не установлены на устройство.

Проверки: `npm run typecheck`, `cargo check --locked --manifest-path src-tauri/Cargo.toml`, `node --test tests/window-close.test.mjs`, `node tests/browser-tray-settings.cjs` (требует Vite на 5180).

Перед выпуском нужен ручной тест настоящего трея Windows: крестик, открытие значком, повторный запуск, «Выйти», закрытие с отключённым переключателем, перезапуск с сохранённой настройкой. Проверки браузера используют подменённый нативный сервис и не заменяют эту проверку.
