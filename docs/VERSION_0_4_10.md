# Orvim 0.4.10 — удобнее записывать и находить

## Тренировки

- У упражнения виден прошлый фактический результат. Кнопка «Повторить результат» подставляет его, не отмечая новую тренировку выполненной.
- В «Подходах» можно записать разные значения и отметить каждый подход одним нажатием. Для веса отдельно сохраняются повторения. Не нужно затем отдельно обновлять цель.
- Цель на результат сравнивается с лучшим выполненным подходом последней тренировки. Накопительная цель складывает фактические значения завершённых подходов. Уже сохранённые тренировки без отдельных подходов используют прежний расчёт.
- По желанию включается таймер отдыха: 60, 90, 120 или 180 секунд. По умолчанию он выключен; звука нет.

## Питание

- Значения можно вводить для всей порции или на 100 г. Во втором случае вес порции пересчитывает калории и БЖУ, а исходные значения сохраняются для последующего изменения.
- «Недавнее» подставляет блюдо в форму. «Повторить вчера» предлагает выбрать нужные записи и добавить их в текущий день; действие можно отменить.
- Дополнительные поля раскрываются в «Подробнее»: приём пищи и источник значений — своя запись, этикетка или примерная оценка. Это указание происхождения данных, не проверка точности.

## Мысли и поиск

- У черновика появляется статус сохранения с подтверждением записи на диск и понятной ошибкой при неудаче. Дата создания мысли сохраняется при редактировании.
- Поиск показывает фрагмент с найденным словом. В открытой мысли совпадения выделяются; поиск по описанию задачи раскрывает нужное поле.
- Ctrl+Shift+N открывает запись мысли из любого раздела, если нет открытого диалога. Ctrl+Enter сохраняет мысль.

## Проекты и расписание

- У проекта есть поиск по названию и описанию записей, переключение «Доска / Список», следующая невыполненная задача и связанные мысли. Существующие материалы и перетаскивание сохраняются.
- В меню задачи или события добавлены «На сегодня / На завтра» с отменой переноса. У тренировки вместе с событием меняется дата самого занятия.
- При редактировании повторяющейся записи можно изменить только её или все невыполненные записи серии. Даты серии сдвигаются на такое же количество дней; завершённые записи, кроме открытой, не меняются.
- Повторы бывают по календарю или после выполнения. Второй вариант создаёт только следующую запись через день или неделю от фактического завершения, до выбранной конечной даты. У повторов сохраняется постоянный ключ для обмена между устройствами.
- Перенос задачи в расписание сохраняет ссылки из мыслей.

## Финансы

- Добавлены счета с названием, валютой, начальным остатком и датой начала учёта. Название и остаток можно изменить. Валюта счёта с операциями фиксируется; удаление такого счёта требует сначала перенести операции.
- Доход или расход можно связать со счётом. Перевод между двумя счетами одной валюты меняет их остатки и не входит в доходы, расходы и диаграмму расходов.
- Остатки подписаны датой конца выбранного месяца. Старые записи без счёта сохраняются и продолжают входить в общую статистику.
- Частую операцию можно сохранить как шаблон и позже открыть с сегодняшней датой для проверки и сохранения.
- Для категории можно задать месячный лимит. Видны использованная часть и остаток, включая категории без расходов. Значение 0 убирает лимит.
- Счета и бюджеты участвуют в существующем обмене записями по локальной сети. Новые данные проверяются при сохранении и восстановлении резервной копии.

## Самочувствие

- У отметки есть необязательные метки контекста и свои метки через запятую.
- В выбранном дне собраны сон, питание, самочувствие, тренировки и события. Записи можно открыть для изменения. Эта история помогает сопоставить события; она не устанавливает причины изменения самочувствия.

## Совместимость и границы

Номер выпуска — 0.4.10. Идентификатор `local.lifeos.client`, схема SQLite 3 и формат документа 31 сохраняются. Версия 0.4.9 в `releases/0.4.9` остаётся отдельно.

Из-за новых типов данных протокол локальной синхронизации обновлён до 2. Для обмена нужно обновить ПК и Android до 0.4.10. Профиль сопряжения сохраняется. Старый клиент не должен пытаться трактовать перевод как расход.

До установки сохраните JSON-копию через настройки. Старые версии не умеют сохранять документ с финансовыми переводами; для возврата на 0.4.9 после использования новых функций понадобится прежняя копия данных.

В этой итерации используются местные записи. Общая база продуктов и распознавание штрихкодов, системный Android-виджет и приём текста из меню «Поделиться» не добавлены. Для них нужен отдельный интерфейс и, для базы продуктов, выбранный поставщик данных.

## Сборка

TypeScript и Vite компилируются; `cargo check --locked` завершился успешно. Собраны Windows EXE/NSIS и Android ARM64 APK. Версии пакетов — 0.4.10; Android versionCode — 4010. Подпись APK совпадает с 0.4.9, проверено выравнивание 16 КБ, совпадение нативной библиотеки с APK и наличие текущих файлов интерфейса в обеих сборках. Итоги и SHA-256 записаны в `releases/0.4.10/build-info.json`.

Автоматические тесты и стресс-тесты в этой итерации не запускались. Поведение новой версии на физическом телефоне, установку Windows и обмен между реальными устройствами ещё нужно проверить. Успешная сборка не подтверждает отсутствие ошибок интерфейса.
