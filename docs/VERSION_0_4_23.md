# Orvim 0.4.23

Сборка от 22 октября 2026 для Windows x64 и Android ARM64.

## Изменения

- Исправлены наложение значка перетаскивания на название задачи на сенсорных экранах и обрезание меню «+» нижней навигацией.
- Исправлено начальное положение расписания и ленты дней тренировок после холодного запуска.
- В ИИ-чате добавлены видимые границы периода, исправлены распознавание дат и сравнение периодов, добавлена остановка запроса. Черновик сохраняется с задержкой, чтобы не записывать всю базу при каждом символе.
- Для больших списков задач добавлены фильтры и загрузка следующих записей порциями.
- План тренировок расположен выше статистики; формы сна и питания — выше истории.
- В финансах доступны месяц, год и произвольный диапазон. Нажатие на месяц годового графика открывает его операции.
- Настройки данных организованы в раскрывающиеся разделы.

Подробности: [исправления аудита](AUDIT_FIXES_2026_10_21.md) и [проверка Android-эмулятора](EMULATOR_QA_2026_10_22.md).

## Установка

- Android: `Orvim-0.4.23-arm64.apk`, обычный пакет `local.lifeos.client`, код версии 4023. Подписан прежним локальным тестовым сертификатом для установки поверх 0.4.22.
- Windows: `Orvim-0.4.23-setup.exe` — установщик; `Orvim-0.4.23.exe` — запуск без установки. Для работы требуется WebView2.
- Предыдущие файлы 0.4.22 сохранены. Перед обновлением полезно сделать резервную копию в настройках приложения. Удалять установленное приложение перед обновлением не требуется.

## Проверки и ограничения

Изменения проверены в браузере, автоматическими сценариями и в изолированном APK на Android-эмуляторе API 36. Проверены создание и сохранение задачи после обновления APK, выполнение и отмена выполнения, меню «+», прокрутка дней, возврат «Сейчас», годовой график финансов.

Перед упаковкой повторно прошли 34 проверки дат и финансов, 24 проверки DOM/таймеров/ИИ-моста и 23 проверки текущих исправлений. Полный набор UI и нативные тесты выполнялись на предшествующем этапе аудита; последние изменения размещения проверены отдельно на эмуляторе. Номер версии обновлён после этой проверки.

Финальные файлы проверяются по версиям, содержимому, контрольным суммам, подписи и выравниванию APK. Эти проверки не заменяют запуск ARM64-сборки на физическом телефоне. Физический Android, установщик Windows вручную, реальные ИИ, микрофон, Health Connect и обмен между устройствами в рамках этого выпуска не проверены. В английском интерфейсе остаются отдельные русские подписи.

Сборки предназначены для личного использования и проверки. EXE не имеет доверенной подписи издателя; APK использует прежний локальный тестовый сертификат.
