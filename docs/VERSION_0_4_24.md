# Orvim 0.4.24 — защита данных

- Основная SQLite-база, обложки в ней и локальные журналы LAN/WebDAV переводятся на SQLCipher. Ключ базы защищается Windows DPAPI / Android Keystore и не выдаётся интерфейсу ИИ.
- Внутренние автоматические JSON-копии защищаются XChaCha20-Poly1305 ключом устройства. Старые управляемые JSON/SQLite-копии в основной папке переводятся на защиту при открытии базы.
- В настройках появились создание переносимой копии с паролем и восстановление. Argon2id: 64 МиБ, 3 прохода, 1 поток; XChaCha20-Poly1305 с отдельными случайными salt/nonce. Пароль не сохраняется. Для каждой ручной переносимой копии его нужно вводить заново.
- Копии с ключом устройства не подходят для переустановки/другого устройства. Автоматическое зеркалирование таких копий во внешнюю папку отключено. Перед удалением приложения сохраните копию с паролем и проверьте восстановление. Старые внешние копии автоматически не переписываются и могут оставаться открытыми.
- При невозможности открыть базу доступно восстановление копии с паролем на стартовом экране. Недоступные файлы сохраняются отдельно.
- При новом открытии чата ИИ доступ к записям сбрасывается. Старую переписку можно включить отдельно. Сообщения текущего разговора передаются для сохранения связности. Доступен просмотр отправляемого сообщения, контекста и истории. Запрос о шагах предлагает только шаги; тренировки и питание добавляются по явному выбору.
- Очистка переписки явно сообщает, что не удаляет данные у провайдера и из старых копий.
- Планы уведомлений приложения защищены DPAPI/Keystore. Заголовки уже переданных системных уведомлений могут храниться самой ОС.
- Включены предыдущие исправления безопасности и обновление упражнений в уже запланированных занятиях.

## Ограничения

Шифрование защищает файлы на диске. Оно не скрывает выбранные для отправки данные от облачного ИИ и не гарантирует защиту от вредоносного ПО в разблокированной системе. Обычный экспорт JSON/CSV и сохранённые отдельно вложения остаются открытыми. Браузерный предпросмотр не получает нативное шифрование. Удаление старых файлов не гарантирует физического стирания блоков SSD/flash.

Эта версия меняет формат хранения: старые APK/EXE не смогут открыть зашифрованную базу напрямую. Для отката потребуется отдельный совместимый экспорт. Протокол синхронизации не менялся; совместимость конкретных старых версий необходимо проверять отдельно.

Не включена необязательная блокировка приложения биометрией. Она требует отдельной проверки фоновых уведомлений и синхронизации.
