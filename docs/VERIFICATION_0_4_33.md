# Проверка Orvim 0.4.33

2 ноября 2026. Использовались изолированные тестовые базы и синтетические данные. База установленного приложения не изменялась.

## Интерфейс и логика

- TypeScript, production-сборка и Clippy прошли.
- Общий набор UI/DOM/логических тестов — 31 набор, включая новые регрессии импорта.
- 693 браузерные проверки: 193 новых сценария круглого центра, общей оценки, прокрутки мыслей и расположения «Моего дня»; 384 адаптивной раскладки; 39 нагрузочных; 36 веса и оценки занятия; 15 личного дня; 26 импорта через интерфейс.
- Основная адаптивная проверка: 320, 390, 430, 720, 768, 1024, 1440 и 1920 px, светлая и тёмная темы. Новые сценарии проверены на шести ширинах из этого диапазона.
- Проверены 1000 мыслей: поиск по всей коллекции, автоматическая подгрузка до последней записи, неподвижность заголовка при прокрутке. Нагрузка главной: 1000 задач и 100 одновременных событий.
- Общая оценка сохраняется после повторной загрузки состояния и не записывается отдельно в упражнения. Подходы и связанные цели продолжают работать независимо от оценки.

## Импорт

- 29 проверок преобразования записей: Notion, разные JSON-оболочки, стабильные ID, стандартные статусы, ночные события Google, повторный импорт, удаление и защита ручных правок.
- 26 браузерных проверок: получить данные → предпросмотр без изменений → применить → повторить. Проверены ошибки доступа и показ импортируемого текста без исполнения HTML.
- 7 native-тестов интеграций делают реальные HTTP-запросы к локальному тестовому серверу с синтетическими токенами: прямой источник Notion, разрешение ID базы в data source, страницы, заголовок версии, неверный токен, неоднозначная база, повторяющийся курсор, пустой и многостраничный Google Calendar.
- Сверены [Notion Query a data source](https://developers.notion.com/reference/query-a-data-source), [переход на API 2025-09-03](https://developers.notion.com/guides/get-started/upgrade-guide-2025-09-03) и [Google Calendar Events.list](https://developers.google.com/workspace/calendar/api/v3/reference/events/list). Приложение использует data sources и проходит страницы по курсору; календарные события запрашиваются в выбранном периоде с раскрытием повторений.

## Native и ограничения

- 68 Rust-тестов прошли; 2 специальных служебных теста штатно игнорируются.
- Один общий тест обнаружения устройств UDP не прошёл и повторно получил системную ошибку Windows 10055 при создании сокета. Он отмечен как недоступный в этой среде, а не как успешно пройденный. Остальные тесты повторно выполнены без него. Настройки сети Windows в рамках этой задачи не менялись.
- Отдельный тест сохранения общей оценки прошёл на реальной временной SQLite-базе: запись, повторное открытие, отклонение неверного диапазона и дробной оценки.
- Живой вход в Notion/Google, личные разрешения аккаунтов, реальные сетевые API, физический телефон и эмулятор в этой версии не проверялись. Browser/native-fixtures не подтверждают фактическую авторизацию конкретного аккаунта.
- При упаковке проверяются версия APK/EXE, прежний Android-сертификат, выравнивание 16 KB, совпадение встроенных JS/CSS и контрольных сумм. Результат фиксируется в build-info.json. Публикация не выполнялась.
