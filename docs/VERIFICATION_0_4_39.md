# Проверка Orvim 0.4.39

Дата: 6 ноября 2026. Локальная Android ARM64 сборка, без публикации и без сборки Windows.

- TypeScript и production frontend build выполнены успешно.
- `node --test tests/widgets.test.mjs tests/window-close.test.mjs`: 9 тестов успешно.
- `node tests/browser-widget-journal.cjs`: перенос мысли, задачи, еды и выполнения в базу; КБЖУ сохраняются; некорректные БЖУ отвергаются; повторный импорт не создаёт дубли.
- Production Rust ARM64, Gradle release и release lint завершились успешно.
- `WidgetNativeTest`: 5 тестов успешно, 23,099 с. Ручные КБЖУ, редактирование фиксированного ответа ИИ и удаление одного блюда перед сохранением, отклонение неверного ответа, зашифрованная мысль, два размера расписания, прокрутка 24 часов и фоновая отметка задачи. Это instrumentation на debug-варианте тех же Android-исходников.
- APK: пакет `local.lifeos.client`, версия 0.4.39 / 4039, прежний сертификат; проверены подпись, 16 KB alignment, совпадение native library и встроенных frontend assets с текущей сборкой.
- Файлы APK 0.4.37 и 0.4.38 не изменены: сверены SHA-256.

## Почему добавлена отдельная проверка release

В 0.4.38 тесты напрямую вызывали рендер виджета в debug-приложении. Это не покрывало обновление через Android broadcast в минифицированной сборке. В этой проверке 0.4.38 расписание оставалось в начальном состоянии без строк часов.

Теперь отдельный `WidgetReleaseInstrumentation` использует только Android framework, устанавливается вместе с распространяемым APK и получает обновления через AppWidgetManager/broadcast. Проверяются все три виджета в обычном framework host и host с AppCompat-контекстом; расписание должно содержать 24 строки часов. На исправленном кандидате все шесть случаев прошли. Разметка использует явно указанные стандартные классы Android, а на API 31+ коллекции передаются напрямую через RemoteCollectionItems.

Итоговый подписанный `releases/0.4.39/Orvim-0.4.39-arm64.apk` также установлен и прошёл все шесть проверок: `OK: 6 packaged widget hosts`. SHA-256: `5AE79755E237F486BEE5BF8262E15D314CEBCE85A52A2305BD6DB37156BE9C8A`.

## Ограничения

- Эмулятор Android 16 / API 36, отдельный пользователь во временном read-only сеансе. Физический телефон пользователя и другие оболочки не проверены. Старый путь RemoteViewsService на Android 7–11 сохранён, но отдельно на этих версиях не запускался.
- Реального запроса к платному провайдеру ИИ не было: в тестовом профиле отсутствуют пользовательские ключи. Проверяются обработка фиксированного ответа, редактирование и сохранение; качество оценки выбранной моделью нужно проверить на телефоне.
- Еда, мысли и задачи сохраняются сразу в зашифрованном журнале виджетов. Перенос в основную базу, её резервные копии и синхронизацию происходит при следующем открытии Orvim.
- APK подписан прежним тестовым сертификатом для личного тестирования, не публичного релиза.
