# Life OS 0.3.4

## Финансы

- Явное создание, переименование и выбор цвета категории. Категории хранятся на устройстве и входят в JSON резервную копию.
- Доходы обозначаются зелёным, расходы красным; категории имеют собственные цветные метки и соответствующие сегменты диаграммы.
- Компактные строки операций и отдельная прокрутка записей месяца.
- При удалении категории её операции переходят в «Другое». Действие можно отменить.

## Интерфейс и управление

- Карточки «Жизни» растут с размером окна и центрируются по доступной высоте. На телефоне сохраняется компактная сетка.
- Короткие формы задач и событий: дата/время доступны сразу, дополнительные параметры раскрываются через «Подробнее». Перед сохранением видны раздел, проект и дата.
- Локальное распознавание «сегодня», «завтра», «послезавтра», today/tomorrow, дат вида 12.10 и времени «в 19:00» / «at 19:00». Распознанные значения видны до сохранения; распознавание можно отменить.
- Общий поиск по задачам, событиям, мыслям, проектам и записям базы данных. Значок поиска на всех устройствах и Ctrl+K на ПК.
- Действия «Изменить», «Перенести», «Дублировать», «Удалить» доступны через меню задачи и записи. Название открывает редактирование; обложка базы открывает просмотр.
- Кнопка «Сейчас» возвращает расписание к сегодняшнему шестичасовому окну.
- Карточки «Жизни» можно скрывать и переставлять без удаления данных: через сам раздел или настройки оформления.
- Самочувствие показывает число записанных дней и, при достаточном количестве записей, изменение дневных средних относительно прошлого месяца. Сравнения сна/нагрузки/тренировок показывают короткий вывод; расчёт и конкретные дни раскрываются отдельно.
- «Готово» в проектах сворачивается нажатием на заголовок; при перетаскивании колонка раскрывается для приёма карточки.
- БЖУ блюда раскрываются по запросу. Запись еды можно изменить нажатием на название. Детали API подключения свёрнуты по группам.
- На узких экранах редакторы открываются снизу и учитывают высоту экранной клавиатуры; кнопки сохранения закреплены внизу формы.
- Общая отмена удаления в течение 8 секунд для задач, проектов, событий, мыслей, операций финансов, записей базы, еды, сохранённых блюд, шаблонов, сна, целей и тренировок. Отмена тренировок возвращает связанные события расписания.

## База данных и архив

- Архив завершённых дел перенесён внутрь базы данных: переключатель «Коллекции / Архив».
- Основное меню: Главная → Жизнь → Мысли → Проекты → База данных. Настройки находятся отдельно внизу.
- Коллекции можно переименовать или удалить. Переименование сохраняет записи; удаление требует подтверждения и допускает отмену с восстановлением записей и обложек.
- Запись базы можно перенести в другую коллекцию в её редакторе.

## Значок Windows

- Windows EXE, установщик и ярлыки используют упрощённый керамический значок B с непрозрачным белым фоном.
- Значок внутри приложения тоже расположен на белой плитке; оттенок фигуры следует выбранной палитре.
- Установщик обновляет источник иконки существующих ярлыков на файл с номером версии, сохраняя их параметры запуска.

## Файлы

- `Life-OS-0.3.4-arm64.apk`: Android ARM64, Android 7 и выше.
- `Life-OS-0.3.4-setup.exe`: установщик Windows x64.
- `Life-OS-0.3.4.exe`: исполняемый файл Windows x64 без установщика.

Данные версии 0.3.3 сохраняются при обновлении. Общая схема локального документа остаётся 30; новые настройки добавлены без замены существующих записей.

Статус сборок и подписи APK записывается в `build-info.json`. Физический Android телефон, его клавиатура/жесты и обновление кэша значков на компьютере пользователя в этой итерации не проверены.
