# Orvim 0.4.31

30 октября 2026.

- На главной рядом со временем появилась кнопка болезни и восстановления. В ней: «Болею с сегодня», «Пропустить только сегодня», «Я выздоровел», другие даты и история.
- Одна отметка действует на сон, питание, тренировки и шаги. Записи можно продолжать; пропуски по болезни не превращаются в нулевые фактические результаты. День выздоровления остаётся днём восстановления, со следующего дня обычный учёт.
- В питании единая карточка журнала с калориями и БЖУ. Ручная форма раскрывается по нажатию, больше нет отдельной колонки. Цель и статистика свёрнуты; ИИ, сохранённые блюда и повтор вчера доступны прямо в журнале.
- Витамины и минералы: выбор названия, количество с упаковки, единица измерения, дата и предварительный просмотр. Можно записывать без дневной цели; ранее добавленные вещества выбираются повторно.
- В статистике для ИИ питание и сон отдельно показывают дни болезни, пропуски по болезни и среднее вне этих периодов. Передаются только разрешённые источники контекста.

Новые поля базы не добавлены: формат 32, совместим с 0.4.30. Для одинакового интерфейса рекомендуется обновить оба устройства. Ранее созданные записи сохраняются.
