# Orvim 0.4.35

3 ноября 2026.

- Исправлены отсутствующие иконки оформления в установленном приложении. Приложение и браузерный тест теперь используют один список иконок.
- Режимы «Системный», «Светлый», «Тёмный» получили мини-иконки с подписями по центру. Цветовые темы — цветные векторные значки; они видны в светлой и тёмной теме.
- «+ Свой шрифт…» перенесён внутрь списка шрифтов. Выбор этого действия открывает файл и не меняет текущий шрифт до успешной загрузки. Отдельная кнопка добавления убрана.
- Круг самочувствия увеличен: 142 px на телефоне и 154 px на ПК. Проверено размещение подписи для системного, мягкого, строгого и Libron.

Предыдущая версия 0.4.34 сохранена. Публикация не выполнялась.
