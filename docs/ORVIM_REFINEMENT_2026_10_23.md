# Orvim: названия, даты, обновления и обложки

## Названия и порядок в папке

- npm/Rust-пакет — `orvim`, исполняемый файл — `orvim.exe`, нативная библиотека — `orvim_lib`.
- Android-классы и файлы `LifePlugin`, `LifeDictation`, `LifeHealthConnect`, `LifeBackups` переименованы в `Orvim…`; регистрация плагина обновлена.
- Новые экспорты и резервные копии получают префикс `orvim-`. Для новой установки база называется `orvim.sqlite3`, папка копий Windows — `Documents/Orvim/backups`.
- Существующая база и папка копий по старым путям продолжают использоваться. Это не создаёт пустую базу вместо пользовательской. Android принимает старые и новые имена копий.
- Обновление ярлыка Windows учитывает прежний `life-os.exe` и переводит ссылку на новый исполняемый файл.
- 247 старых HTML-макетов и изображений перенесены из корня `.artifacts` в `.artifacts/archive/orvim-previews-2026-10-23`, названия заменены на Orvim. Таблица перемещения — `rename-map.json`; ссылки между перенесёнными HTML-файлами обновлены.
- Предыдущие APK/EXE, пользовательские вложения, базы и ключи не удалялись. Функции приложения не удалялись без уточнения того, что считать лишним.

### Почему остались технические упоминания

`local.lifeos.client` — идентификатор уже установленного Android-приложения и его хранилища. Замена дала бы другое приложение. Формат старых копий, идентификаторы защищённого хранилища, протокол синхронизации, системные события и совместимость установщика тоже сохраняются. Эти строки не являются отображаемым названием продукта. Кэш сборки, зависимости и исторические выпуски не переименовываются массовой заменой. Корень текущей рабочей папки остаётся `<checkout Orvim>`; перенос работающего checkout не выполнялся.

## Текущая дата

При входе через основную навигацию, открытии категории Жизни, возврате приложения на экран и смене суток обновляются дни расписания, самочувствия, питания, сна, тренировок и шагов; финансовые периоды переводятся на текущий месяц/год. Выбор дня при просмотре истории остаётся доступен. Открытый диалог и активный ввод защищены от автоматического сброса даты. Новые даты не записываются в существующие события или тренировки.

## Обновления

Показаны установленная версия, время успешной проверки, понятный результат и состояние загрузки. Повторная проверка во время запроса блокируется. Предыдущие версии убраны под раскрывающийся пункт. Согласована минимальная поддержка документа 31 в интерфейсе и нативной проверке.

Если подписанный канал ещё не настроен, проверяются сведения о публичном последнем выпуске GitHub, с переходом на его страницу для ручного обновления. Закрытый репозиторий, отсутствие публичного выпуска, лимит запросов и ошибка сети не выдаются за «у вас последняя версия». Установка из приложения по-прежнему требует подписанный манифест и проверку хеша. Новые настройки используют `ORVIM_UPDATE_`, старые переменные поддерживаются как резервные.

Публикация GitHub Release, создание ключа подписания обновлений и подключение производственного канала в этом изменении не выполнены. Порядок подключения: [UPDATES.md](UPDATES.md).

## Обложки: варианты кроме Википедии

На 23 октября 2026 проверены официальные описания сервисов:

| Источник                                                                | Для чего                                       | Условия подключения                                                                                                                 |
| ----------------------------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| [Open Library](https://openlibrary.org/dev/docs/api/search)             | Книги, поиск названия и идентификатора обложки | Уже подключён. Теперь приложение пробует до трёх кандидатов вместо одного, в пределах общего ограничения времени                    |
| [TMDB](https://developer.themoviedb.org/docs/image-basics)              | Постеры фильмов и сериалов                     | Поиск требует отдельного подключения API; прямые HTTPS-ссылки `image.tmdb.org` уже разрешены загрузчиком                            |
| [Google Books](https://developers.google.com/books/docs/v1/using)       | Альтернативные издания книг                    | Официальная документация требует API-ключ или OAuth для публичных запросов; прямые ссылки с разрешённых хостов уже поддерживаются   |
| [DeepSeek Search / Fetch](https://api-docs.deepseek.com/guides/search/) | Поиск страниц и получение их содержимого       | Отдельные API-вызовы с ключом DeepSeek; обычный запрос чата их сам не выполняет. Результат — страницы, а не гарантированная обложка |

Рекомендация: использовать специализированный каталог для обложек и предлагать пользователю несколько кандидатов. DeepSeek может уточнить название и запустить инструмент поиска. Нельзя просить модель придумать адрес картинки: это даёт несуществующие ссылки и неправильные изображения. Для TMDB нужны ключ и [атрибуция](https://developer.themoviedb.org/docs/faq); правила коммерческого использования отличаются. DeepSeek Search/Fetch тарифицируются отдельно по правилам сервиса. Платные запросы с пользовательским ключом не выполнялись, новые внешние интеграции в этой правке не подключались.

## Проверка

Веб-сборка и проверка типов прошли. Нативный Rust и переименованные Android-классы Kotlin компилируются. Автоматические тесты, эмулятор и выпуск новых APK/EXE в этом этапе не запускались. Последние выданные файлы 0.4.23 не содержат этих новых изменений.
