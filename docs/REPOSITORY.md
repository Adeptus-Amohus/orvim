# Основной репозиторий Orvim и происхождение выпуска

Основной адрес проекта: **https://github.com/Adeptus-Amohus/orvim**. Здесь размещаются исходники приложения, README, документация, сайт в `site/` и публичные выпуски. Сайт сохраняет адрес https://adeptus-amohus.github.io/orvim/.

## Что объединяется

Ранее `Adeptus-Amohus/life-os` был приватным репозиторием приложения, а публичный `Adeptus-Amohus/orvim` — репозиторием сайта, обратной связи и готовых файлов. Переименование локальной папки не меняло GitHub remote; поэтому первая публикация 0.4.46 попала в life-os. Позднее те же APK/EXE были опубликованы в Orvim без пересборки.

Теперь в существующий Orvim добавляется проверенный снимок исходников приложения. Публичная история сайта сохраняется. Приватная история life-os, старые ветки, теги и выпуски остаются в прежнем репозитории; они не раскрываются вместе со снимком. Личные материалы, базы, ключи, пароли, локальные кеши и `.artifacts` не переносятся.

## Сайт и CI

Корень репозитория содержит приложение; сайт публикуется из `site/` через отдельный GitHub Actions workflow. Это сохраняет прежний URL и не публикует приложение как статическую страницу. Такой способ описан в [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Workflow сборки приложения сохраняется отдельно. При отсутствии Android signing secrets CI выдаёт **unsigned artifact** для проверки компиляции. Такой артефакт не заменяет подписанный APK стабильного выпуска. Локальный существующий keystore не загружается в GitHub автоматически. Публичные инструкции не требуют доступа к приватным документам.

## Языки и состав файлов

Прежний публичный Orvim содержал HTML, CSS и JavaScript сайта. В исходниках приложения есть большие JavaScript-модули интерфейса и логики, TypeScript/TSX оболочка, Rust-хранилище и IPC, Kotlin/Gradle Android, CSS, тесты и вспомогательные сценарии. Поэтому доли языков после добавления приложения будут другими.

В исходном снимке 640 отслеживаемых файлов: 49 `.js` (1 178 224 байта), 30 `.rs` (429 293), 20 `.tsx` и 22 `.ts` (149 576 суммарно), 18 `.kt` (150 952); отдельно есть тесты `.cjs`, инструменты `.mjs`, CSS и HTML. Это инвентаризация расширений до нового оформления, а не точный расчёт GitHub Linguist. Лицензии, шрифты, звуки, изображения и lockfiles также занимают место, но не означают долю написанного на языке кода.

Искусственные правила `linguist-language`, `linguist-generated` или `linguist-vendored` ради изменения процентов не добавляются. Выбор технологий отражён в реальных файлах, а не в цвете диаграммы GitHub.
