# Orvim 0.4.36

Тестовая сборка от 4 ноября 2026.

- Одинаковые отступы между мини-иконками и названиями цветовых тем.
- Дополнен английский перевод настроек, «Моего дня», показателей, форм и подсказок. Пользовательские названия и заметки сохраняются.
- Встроенная диктовка убрана из чата. Голосовой ввод доступен через клавиатуру ОС; разрешение RECORD_AUDIO удалено из Android-манифеста.
- Обновлены инструкции по шифрованию, копиям, переносу, обновлениям и подписи Android. Зафиксированы пользовательские проверки установки и миграции.

APK использует прежний тестовый сертификат и package ID для обновления поверх установленной версии. Постоянная публичная подпись не менялась, выпуск в интернете не публиковался.

Для проверки: обновить APK/EXE поверх существующей версии, проверить сохранность записей, английский интерфейс, отступы тем, ввод и исправление фразы через микрофон клавиатуры и сохранение черновика ИИ. Перед обновлением рекомендуется независимая копия с паролем.
