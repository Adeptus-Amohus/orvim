# Проверка Orvim 0.4.27

- Браузер: 36 проверок отступов главной, сетки подключений, отсутствия удалённых настроек и подтверждения/отказа сброса на 320/390/1020/1280. Дополнительно 77 проверок чата и 69 сна/питания.
- Нативная часть: 58 Rust-тестов прошли; два сетевых smoke-теста исключены из общего набора и выполнены отдельно. Clippy и проверка типов прошли. Общие UI-тесты прошли.
- Живой публичный поиск: скачаны постер фильма «Дюна (2021)» и обложка романа Dune. Проверяется точное название, а не только успешная загрузка произвольного изображения.
- Импорт Notion и Google Calendar проверен настоящим HTTP-клиентом на локальном тестовом сервере: разрешение базы Notion, две страницы, неверный токен, пустой календарь, повтор курсора. В доступном профиле не найдены сохранённые подключения Notion/Google; с настоящими аккаунтами вход/обмен не подтверждён.
- Wi-Fi: реальный loopback TCP, неправильный код, одноразовость кода, отзыв устройства, неправильный ключ, подмена шифртекста/направления, новый nonce и отказ повторного сообщения на другом соединении. Полный внешний пентест и перехват на домашнем роутере не выполнялись.
- Сброс: удаление всех коллекций, старых таблиц и внутренних снимков с повторным открытием базы; интерфейс не разрешает удаление без ввода Orvim. При ошибке возобновляются записи и обмен. Пользовательская база не очищалась.
- GitHub: через сохранённую авторизацию подтверждены private=true и пустой список releases у Adeptus-Amohus/life-os; без авторизации 404. Закрытый ключ обновлений создан вне репозитория, в сборках только открытый ключ. Публикация ожидает решения владельца.

Android 16, отдельный искусственный профиль: APK 0.4.27 установлен поверх 0.4.26, тестовая запись сохранена. Через интерфейс выполнено подтверждённое удаление всех данных; тестовая мысль исчезла, настройки сброшены. Физический телефон, микрофон и UI установщика Windows в этом этапе не проверялись. Шифрование трафика не скрывает IP/имя устройства, размеры и время пакетов и не защищает от вредоносного ПО на разблокированном устройстве.

Использованы официальные описания [Notion data sources](https://developers.notion.com/reference/query-a-data-source), [Google Calendar events](https://developers.google.com/workspace/calendar/api/v3/reference/events/list) и [GitHub Releases](https://docs.github.com/en/rest/releases/releases).
