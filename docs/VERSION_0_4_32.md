# Orvim 0.4.32

## Главная и оформление

- Исправлен большой промежуток между расписанием и задачами на телефоне: ограничение высоты для настольной сетки больше не применяется к мобильной раскладке.
- Высота списка задач подстраивается под содержимое; длинный список прокручивается внутри ограниченной области.
- Карточки и элементы управления используют плоское оформление и скругления, без объёмных теней. Фокус клавиатуры остаётся видимым.

## Питание

- Вес находится внутри питания и выключен по умолчанию. Включение: «Питание → Дополнения → Вес».
- В дополнениях только три переключателя: вода, вес и БЖУ. Калории показываются всегда, включая обновление со старой версии, где они были скрыты.
- Убраны интерфейс витаминов и минералов и соответствующий источник контекста ИИ. Ранее записанные данные остаются в формате резервной копии, чтобы обновление не уничтожало личные записи.
- Ручное добавление еды остаётся свёрнутым, основные действия и калории находятся в одном журнале питания.

## Мой день

- Настройка перенесена в «Настройки → Оформление → Мой день». На экране жизни больше нет отдельной большой панели.
- Например, при начале в 22:00 личный день длится до 22:00 следующей календарной даты. Записи с известным временем группируются по этому интервалу.
- Изменение начала дня автоматически запрашивает новые суточные суммы шагов из Health Connect. Это работает и при получении настройки через синхронизацию.
- Ответ от часов для предыдущей границы дня не заменяет новые данные. При ошибке обновления старые суммы не выдаются за пересчитанные; сохранённые записи не удаляются.
- Сон с часов отображается по времени окончания. Явно изменённая вручную дата сна сохраняется.
- Старые записи без времени и вручную введённые суточные итоги сохраняют выбранную дату: распределить их по часам без исходных данных невозможно.

## Болезнь и восстановление

- Открывается нажатием на часы на главной. Отдельная кнопка с крестом убрана.
- В окне используется небольшая плоская медицинская эмблема с крыльями в духе Trauma Team.
- Во время отмеченного периода рядом со временем появляется подпись «Восстановление». Можно продолжать записывать показатели или пропустить день без оценки выполнения целей.
