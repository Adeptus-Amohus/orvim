# Life OS 0.4.1 — разговор с ИИ

## Что изменено

- Открывается переписка, а не большая форма выбора данных. Ваши сообщения справа, ответы ИИ слева. История сохраняется локально, последние 40 сообщений доступны в разговоре.
- Сообщение появляется сразу после отправки. Поле ввода очищается сразу, новый черновик не стирается при получении ответа. Пока модель отвечает, в переписке видно ожидание.
- Поле ввода закреплено снизу. На ПК Enter отправляет, Shift+Enter добавляет строку; на сенсорном устройстве Enter оставляет возможность писать несколько строк.
- Данные Life OS добавляются отдельно по кнопке «Добавить контекст». Можно писать без них. Выбранный проект включает описание, задачи и события этого проекта.
- Выбранные записи показаны плашками с удалением. «Что увидит ИИ» показывает понятные названия и значения вместо JSON. При большом выборе предпросмотр показывает первые 30 записей каждого раздела и число остальных; сам запрос содержит весь выбранный контекст.
- «Сохранённые наборы» раскрываются по желанию. Набор хранит выбор; содержимое записей обновляется перед каждым запросом.
- Ошибка показывается рядом с сообщением, доступна кнопка «Повторить». Последнее неудачное сообщение повторяется без дублирования. Если уже набран следующий текст, ошибка его не перезаписывает.
- Кнопка возврата, Escape и Android «Назад» из выбора данных возвращают в разговор. Закрытие чата останавливает микрофон. Облачное распознавание по-прежнему требует отдельного разрешения.

## Как пользоваться

1. «Настроить ИИ»: сохраните ключ, проверьте подключение и выберите модель.
2. Напишите запрос обычными словами. Категории данных — это не вопросы, на них не нужно отвечать.
3. Для анализа конкретного проекта нажмите «Добавить контекст» → «Проекты», отметьте проект → «Готово».
4. Продолжайте переписку, отвечая на вопросы ИИ. Создание и изменение записей по-прежнему требует подтверждения предложенных изменений.

## Границы проверки

TypeScript, производственные сборки Windows EXE/NSIS и Android ARM64 APK прошли. Подпись APK проверена и совпадает с 0.4.0; номер версии 0.4.1, versionCode 4001, выравнивание APK 16 КБ проверено. Файлы и SHA-256 находятся в `releases/0.4.1/build-info.json`.

Изображения сняты с реального интерфейса в Chrome на мобильной и настольной ширине; содержимое разговора демонстрационное, запросы платному провайдеру не выполнялись. Физический Android, экранная клавиатура и личный API-ключ не проверены в этой итерации. Полный набор тестов 0.4.0 в этой итерации не запускался.

Ответ модели отображается целиком после получения; потокового вывода по словам пока нет. Формат пользовательских записей и схема SQLite не менялись. Сборка APK использует прежний личный тестовый сертификат.
