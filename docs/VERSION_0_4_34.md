# Orvim 0.4.34

3 ноября 2026.

- Удаление события сразу обновляет расписание и список задач на главной. Отмена удаления сохранена.
- Меню задач: изменить, перенести, дублировать, удалить. Быстрые пункты «На сегодня» и «На завтра» убраны.
- Качество сна выбирается луной по шкале 1–5, пальцем или клавишами. Сохранение — вместе с записью сна; оценку можно очистить.
- Дополнения питания открываются иконкой ползунков с подписью для доступности.
- В меню запланированного занятия остались изменение, повторение, удаление и удаление нескольких занятий. Сохранение шаблона и обновление запланированных занятий доступны в «Моих занятиях».
- В финансах период, валюта, счета и фильтр по счёту свернуты под иконкой настроек. Итоги и добавление операции находятся сверху.
- У названий карточек Kanban увеличен вертикальный запас для букв и снято обрезание текста.
- В настройках коллекции название статуса и его роль в прогрессе разделены подписями; каждый статус находится в отдельной округлой строке.
- Самочувствие: по умолчанию три напоминания — 09:00, 15:00, 21:00. В настройках уведомлений можно выбрать от одного до шести в день; время каждого напоминания показано рядом. При уже сделанной отметке соответствующее напоминание пропускается.
- В настройках уведомлений есть отдельный выключатель звука таймера тренировки и прослушивание.
- У режимов оформления и цветовых тем добавлены иконки, у своего цвета — палитра.
- Можно добавить до 10 своих шрифтов TTF/OTF/WOFF/WOFF2, до 5 МБ каждый. Шрифт проверяется перед сохранением. Файлы остаются на устройстве, не входят в резервную копию базы и не передаются синхронизацией; на другом устройстве их нужно добавить отдельно. Встроенные шрифты сохранены.

Версия 0.4.33 сохранена отдельно. Публикация на GitHub не выполнялась.
