# Orvim 0.4.9 — выполнение задач

## Изменения

- Галочки во всех списках используют один тонкий векторный знак по центру скруглённого квадрата. Выполненный пункт имеет лёгкую заливку вместо сплошного цветного кружка.
- На Главной сначала идут все невыполненные задачи и события на сегодня, затем группа «Выполнено» с количеством. Внутри обеих групп сохраняется порядок по времени. Снятие отметки возвращает запись в активную группу.
- После выполнения фокус переходит к невыполненной задаче без скачка прокрутки к завершённому пункту.
- Завершённые тренировки занимают компактную строку. Подробные результаты доступны нажатием на название; их значения и прогресс цели сохраняются.
- Названия в списке Главной больше не зачёркиваются и остаются читаемыми. Название берётся из сохранённой записи и защищено от перевода интерфейса. Проверки обычной задачи и тренировки подтверждают сохранение текста после выполнения и перезапуска. Подмена названия на случайный текст из присланного снимка не воспроизведена; личные записи автоматически не переименовывались.

## Проверки

- Полный набор `npm run test:ui` проходит. Добавлены проверки порядка выполненных записей, возврата в активные и сохранения названия.
- Браузерный аудит: 209 проверок, без ошибок выполнения. Проверены все разделы, формы, темы, шрифты, ширины 320–1920 пикселей, масштаб 80–150%, 1000 задач и 300 пересекающихся событий, колесо и сенсорная прокрутка.
- Отдельный браузерный набор: 30 проверок переписки ИИ, сохранённого контекста, предпросмотра изменений, резервных копий и сравнения синхронизации. Исправлена гонка тестового сценария: фоновый опрос имитации синхронизации мог затереть вручную подставленное состояние сравнения.
- Rust: 42 теста проходят, включая сохранение и синхронизацию 10 000 задач, восстановление после завершения процесса и защищённое хранение ключей. Для проверки защищённого хранилища потребовался запуск вне ограничения файловой песочницы.
- TypeScript, Rust fmt и Clippy проходят.

Проверки интерфейса выполнялись в изолированном Chrome с тестовыми данными. Личная база не изменялась. Отчёты и изображения находятся в `.artifacts/ui-audit/`; копии отчётов включены в выпуск.

## Установка

Файлы находятся в `releases/0.4.9`:

- `Orvim-0.4.9-setup.exe` — установщик Windows.
- `Orvim-0.4.9.exe` — запуск без установщика, с установленным WebView2.
- `Orvim-0.4.9-arm64.apk` — тестовая сборка Android ARM64.

Установка поверх предыдущей версии. Идентификатор `local.lifeos.client`, схема SQLite 3, формат документа 31 и сертификат Android сохраняются. Подпись, версии и содержимое проверены при упаковке; сведения находятся в `build-info.json`.

Новый установщик на рабочем ПК не запускался. APK на физическом телефоне не проверялся. Браузер использует имитацию нативных служб, поэтому реальные разрешения Android, системные уведомления и импорт Health Connect этой проверкой не подтверждаются.
