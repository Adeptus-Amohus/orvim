# Life OS 0.3.6

- Локальная синхронизация Windows ↔ Android: сопряжение по одноразовому коду, зашифрованный обмен, автоматические повторы и выбор конфликтующих версий.
- Казахский язык: автоматическое определение языка устройства и ручное переключение RU / EN / Қазақша. Добавлены символы казахского языка для мягкого и строгого шрифтов, даты, голосовой язык и тексты уведомлений.
- API подключения: сохранение ключа с проверкой защищённого хранилища, заметный статус возле поля, проверка подключения и выпадающий выбор модели. Ошибки HTTP объясняют следующий шаг.
- У Windows значка и эмблемы в приложении убрана белая подложка. Керамическая форма и латунные детали сохранены; Android значок остаётся на прежнем белом фоне.

Инструкции: [подключение двух устройств](LOCAL_NETWORK_SYNC.md), [GPT](OPENAI_CONNECTION.md).
