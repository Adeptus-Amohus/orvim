# Перенос Orvim через USB

Этот режим не использует Wi-Fi, адреса ПК, QR или сетевое сопряжение. Кабель переносит зашифрованный файл между устройствами; Orvim затем сравнивает и объединяет его содержимое.

1. На устройстве с исходными данными откройте **Настройки → Данные → Перенос по USB → Подготовить файл**.
2. Задайте пароль от 12 символов, повторите его и сохраните файл. На телефоне удобно выбрать «Загрузки».
3. Подключите телефон к ПК, разблокируйте его и выберите режим USB **Передача файлов**. Через Проводник скопируйте `Orvim-transfer-…json` в обычную папку ПК. Для направления ПК → телефон скопируйте файл в «Загрузки» телефона.
4. На принимающем устройстве откройте **Перенос по USB → Открыть файл и объединить**, выберите файл и введите тот же пароль.
5. Просмотрите сравнение. Совпадающие записи не дублируются. У новых записей можно снять отметку принятия. Если одна запись отличается, выберите данные этого устройства или данные файла. Сам факт того, что файл создан позже, не доказывает актуальность каждого его поля — ориентируйтесь на показанные значения и даты.
6. Нажмите **Применить выбранное**. До этого записи не меняются. Перед применением сохраняется внутренняя резервная копия.

Для обратного направления подготовьте новый файл на устройстве с итоговыми данными и повторите перенос. Это ручной обмен через файл, автоматического чтения телефона при подключении кабеля в этой версии нет. Если Windows не показывает телефон, проверьте режим USB и кабель, поддерживающий передачу данных.

Файл включает рабочие записи и изображения. API-ключи, переписка ИИ, тема, шрифт и уведомления остаются на своих устройствах. Записи, отсутствующие в файле, не считаются удалёнными. Один уже применённый файл не применяется повторно; для новых данных создайте новый.

Пароль не хранится в файле в открытом виде. Без него содержимое не восстановить. USB сам по себе не заменяет шифрование: пароль защищает скопированный файл, если он останется в общей папке или потеряется вместе с носителем.
