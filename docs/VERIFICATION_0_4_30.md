# Проверка Orvim 0.4.30

Дата: 29 октября 2026. Изолированные тестовые данные; личная база установленного приложения не изменялась.

Проверены:

- TypeScript и production-сборка интерфейса.
- Rust: 67 тестов прошли, 2 служебных теста пропущены штатно. Включены сохранение/повторное открытие новых коллекций, строгая проверка чисел, дат, единиц и сложности упражнения, шифрование, перенос и синхронизация.
- Clippy с запретом предупреждений.
- Общий набор DOM/логических тестов и отдельные тесты личного дня. Границы 21:59/22:00, новый год, високосная дата, сохранение старых записей без времени, пересечение периодов болезни, незаписанные дни, частичный контекст ИИ и единицы веществ.
- Браузерные сценарии: 320, 390 и 1440 px для новых форм. Запись и исправление веса, график, болезнь/выздоровление, витамины/цель, отключение учёта без потери истории, повторная загрузка состояния и добровольная оценка упражнения. Отсутствие горизонтального переполнения и ошибок JavaScript.

Отдельные журналы: `.artifacts/health-030-*.log`. Снимки интерфейса: `.artifacts/life-tracking-030-*.png`.

Браузерные тесты используют имитацию native-сервисов. Реальный аккаунт ИИ, физические часы, импорт из личного Health Connect, камера телефона, копирование файла по настоящему USB и интерфейс нового установщика на пользовательском ПК этими проверками не подтверждены. Проверки подписи APK, версии пакетов и совпадения встроенных ресурсов фиксируются отдельно в `releases/0.4.30/build-info.json` после упаковки.
