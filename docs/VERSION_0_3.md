# Life OS 0.3.0

## Интерфейс

- База данных: отдельная иконка дискового хранилища, каталог с обложками и оценками по половине звезды.
- Архив: самостоятельный раздел бокового меню для завершённых задач и событий. Есть поиск, фильтр по проекту, редактирование, возврат в работу и отмена удаления. В проектах остаются Доска и Мысли.
- Настройки: Оформление, Уведомления, Данные, Подключения. В подключениях отдельно доступны ИИ-помощник, импорт из сервисов и календари; внутри каждого сервиса сгруппированы доступ и параметры работы.
- Текущая иконка римского додекаэдра сохранена. Линейные варианты с цветом темы подготовлены отдельно для выбора.

## Изменения версии

- Редактирование задач и проектов по названию и через меню; исправлена работа «Изменить».
- Явный светлый и тёмный режим независимо от темы устройства; системный режим остаётся вариантом первого запуска. Добавлен локальный шрифт Libron.
- Прокрутка расписания жестом и колёсиком. Сокращены лишние перестроения календаря и обработчики устаревших строк.
- Уведомления за пять минут до незавершённых событий и раз в четыре часа для самочувствия. Нет уведомлений у задач без времени.
- Мысли, финансы вместо восстановления, сохранённые упражнения.
- API ключи OpenAI, DeepSeek и Gemini, голосовой ввод и предпросмотр изменений помощника перед применением.
- Импорт Notion / JSON API, обмен событиями Google Calendar на ПК и системным календарём Android.
- Миграция хранилища до формата 30 сохраняет прежние записи. Новые коллекции входят в резервную копию; API ключи в неё не входят.

## Проверки

- TypeScript и production Vite build.
- 300 проверок интерфейсной логики в JSDOM: меню, редактирование, архив, вкладки настроек, самочувствие, мысли, финансы, упражнения, полузвёзды, предпросмотр ИИ и другие существующие сценарии.
- 12 проверок очереди сохранения и 20 проверок преобразований данных и планировщика напоминаний.
- 14 проверок Rust/SQLite, включая миграцию со второй версии схемы, сохранение всех коллекций, 10 000 задач и шифрование ключей Windows; Rustfmt и Clippy без ошибок.
- Сборка Windows и ARM64 APK выполняется из одинаковых исходников. Контрольные суммы и проверка подписи лежат рядом с установочными файлами.

JSDOM проверяет действия и состояние, а координаты жестов моделируются. Эти проверки не подтверждают реальные пиксельные размеры, масштабирование, скорость скролла, доставку системных уведомлений или работу микрофона на конкретном телефоне. Подключения проверены с имитацией сервисов, без реальных пользовательских API ключей и аккаунтов.

## Установка и ручная проверка

Локальные файлы находятся в `releases/0.3.0`: установщик Windows, отдельный EXE и APK ARM64. APK предназначен для локальной проверки и подписывается тем же локальным тестовым ключом, что и версия 0.2.0.

1. Открыть базу данных и архив: это разные разделы. Завершить задачу, найти её в архиве, изменить, вернуть в работу.
2. В настройках открыть четыре раздела и каждое подключение. Проверить скачивание копии, импорт с предпросмотром и отмену восстановления.
3. Проверить Светлый / Тёмный режим при противоположной теме устройства, шрифты, узкое окно и увеличение текста.
4. На телефоне проверить свайп расписания, клавиатуру в формах, выбор файлов, голосовой ввод и системные разрешения.
5. Проверить уведомление события за пять минут до начала и самочувствие после четырёх часов, включая закрытое приложение. Поведение фоновых уведомлений зависит от системных разрешений и ограничений устройства.
6. Подключения календарей и API проверять на своих аккаунтах: сначала получить данные и изучить предпросмотр, затем применить или отправить изменения.

Автоматической синхронизации базы между ПК и телефоном пока нет. Перенос данных между устройствами доступен через резервную копию.
