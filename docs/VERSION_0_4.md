# Life OS 0.4.0 — отчёт по требованиям

Работа выполнена в `<checkout Orvim>`, исходная ветка `codex/version-0.3`, исходный commit `43b9718`. Рабочая копия перед началом была чистой. Пользовательские данные не сбрасывались. Установленная SQLite была прочитана только для проверки целостности и счётчиков; тесты записи, удаления и завершения процесса использовали отдельные синтетические базы. Обязательного аккаунта нет.

- `npm run test:ui`: **441 проверка**, включая очередь записи, даты, действия, контекст, диктовку с паузами и существующие разделы.
- `cargo test`: **42 теста**, реальные SQLite записи/повторное открытие, принудительное завершение дочернего процесса, 10 000 задач, транзакции, backup/restore, TCP/UDP/ETag, конфликты/повторы и подписи. Один тест — вспомогательный entry point дочернего процесса.
- TypeScript, Rustfmt, Clippy с `-D warnings`, `git diff --check`.
- Chrome: **30 проверок** нового ИИ/сравнения/масштаба/нагрузки + **108 production проверок** всех разделов/тем/шрифтов/копии/повторного открытия. В production нагрузке 1000 задач + 300 пересекающихся событий, высота списка остаётся ограничена, последняя задача редактируется. Браузерные профили изолированы от установленных пользовательских данных.
- Сборки Windows x64 EXE/NSIS и Android ARM64 APK. Итоговые файлы и SHA-256 — `releases/0.4.0/build-info.json`. APK подписывается тем же **личным тестовым** сертификатом, что предыдущая сборка; это не production сертификат.

## Не проверено на устройствах / требует настройки

Телефон отсутствует: реальное распознавание речи, permissions/SAF, камера/deep link, системный установщик/уведомления и Ethernet↔Wi-Fi требуют пользовательской проверки. Перезагрузка ОС, uninstall/reinstall, обновление установленного пользовательского приложения и фактический rollback не выполнялись. UI на мобильных размерах проверялся в Chrome Windows, не в физическом Android WebView.

Полное удаление очищает записи и управляемые копии Life OS на этом устройстве. Вручную экспортированные JSON/CSV, оригиналы прикреплённых файлов, копии на других устройствах и WebDAV остаются: перед продажей устройства удалите их отдельно. Наличие физической копии и её восстановление нужно проверить до удаления Android приложения.

Для ИИ нужен личный ключ и доступная модель. Для внешнего обмена — выбранный вами HTTPS WebDAV с сильным ETag и общий ключ. Для обновлений — ваш Ed25519 ключ вне Git, встраивание открытого ключа и публикация подписанного списка пакетов. Отсутствие этих ресурсов не заменено фиктивным успешным результатом.

## Как начать проверку

1. Установите 0.4.0 поверх предыдущей версии. Не удаляйте старую Android версию для обычного обновления.
2. На Android выберите отдельную внешнюю папку копий. Создайте копию и убедитесь, что файл появился; на ПК проверьте Настройки → Данные → Управлять копиями.
3. Создайте проект, мысль, задачу без времени и событие с сегодняшним временем. На главной должна появиться только назначенная запись со временем. Перезапустите приложение.
4. Подключите ИИ, сохраните набор проекта с задачами; проверьте создание проекта и отмену. Продиктуйте две фразы с паузой, затем явно нажмите Stop.
5. Сопрягите ПК Ethernet и телефон Wi-Fi; проверьте ID, сравните правку/удаление, отклоните одну запись и повторите обмен. Проверьте внешнюю копию перед экспериментами с установкой/откатом.
