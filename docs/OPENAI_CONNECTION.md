# Как подключить GPT в Orvim

1. Откройте [страницу API ключей OpenAI](https://platform.openai.com/api-keys), создайте ключ для своего проекта и скопируйте его. Orvim использует API ключ, а не пароль от аккаунта.
2. В **установленном** Orvim откройте **Настройки → Подключения → ИИ-помощник** и выберите **OpenAI**.
3. Вставьте ключ целиком, без пробелов, в **API ключ** и нажмите **Сохранить ключ**. Появится статус **Ключ сохранён на устройстве**. Orvim проверяет, что защищённое хранилище действительно сохранило ключ.
4. Поле ключа после сохранения становится пустым — так ключ не показывается в интерфейсе. Он остаётся на устройстве. При повторном открытии подключений статус подтверждает его наличие.
5. Нажмите **Проверить подключение** или **Загрузить модели**. Если ключ подходит, появится список. Выберите текстовую GPT модель в выпадающем поле **Модель**. Модель можно также указать вручную, если вы знаете её точное API название. Выбор сохраняется автоматически.
6. Закройте настройки и нажмите значок ИИ в верхней части приложения. Выберите, какие разделы разрешено анализировать, введите запрос и нажмите **Отправить**. Предлагаемые изменения сначала показываются для подтверждения.

Проверка подключения загружает список моделей; она не отправляет ваши записи и не генерирует ответ. Данные выбранных разделов отправляются OpenAI только при отправке запроса помощнику.

## Если не работает

- **HTTP 401**: неверный или отозванный ключ. Создайте новый и сохраните его.
- **HTTP 403**: у ключа или проекта нет разрешений для выбранной функции / модели.
- **HTTP 404**: неверное название модели. Загрузите модели и выберите доступную.
- **HTTP 429**: проверьте баланс, ограничения расходов и лимиты API в [Billing](https://platform.openai.com/settings/organization/billing/overview).
- **Нет подключения к сервису**: проверьте интернет на устройстве.
- **Функция доступна в установленном приложении**: браузерная демонстрация не сохраняет API ключи; нужен EXE или APK.

Ключ не включается в резервные копии и не синхронизируется с другим устройством. На телефоне его нужно сохранить отдельно. Если сохранение не удалось, поле не очищается и отображается ошибка рядом с ним.

Создание ключа и API запросы описаны в [официальной инструкции OpenAI](https://developers.openai.com/api/docs/quickstart). Хранение проверено синтетическим ключом и средствами DPAPI; реальный запрос с личным ключом пользователя в ходе разработки не выполнялся.
