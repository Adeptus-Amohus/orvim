# Выбранные звуки уведомлений

- `wellbeing-compact.wav` — Short Compact, 1,05 секунды, для самочувствия.
- `schedule-warm.wav` — Velvet Warm, 1,9 секунды, для расписания.

Точные копии выбранных кандидатов из `../candidates/v4`, без изменения звучания.
Формат: WAV, PCM 16 bit, stereo, 44,1 кГц. Это оригинальные синтезированные
звуки Orvim.

В **Настройки → Уведомления** можно выключить все уведомления, отдельно
самочувствие или расписание, либо только звук. «Прослушать» запускает
короткий образец по нажатию. Параметры сохраняются вместе с локальной базой
и включаются в резервную копию.

Расписание напоминает за 5 минут до начала; задачи без времени не уведомляют.
Самочувствие напоминает раз в 4 часа с момента последней отметки.
Звук при сохранении самочувствия и прокрутке расписания не добавляется.

Windows включает WAV в исполняемый файл и сохраняет копии в локальной папке
приложения для запланированных системных уведомлений. Android использует
копии в `res/raw` и отдельные каналы для каждого вида уведомлений со звуком
и без звука. Настройки проверяются повторно при доставке Android-уведомления.
