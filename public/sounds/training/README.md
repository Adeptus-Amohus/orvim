# Сигнал окончания отдыха

`rest-ready.wav` — отдельный оригинальный сигнал таймера занятия: три мягких
высоких ноты, 0,95 секунды, PCM 16 бит, стерео, 44,1 кГц. Создан процедурно
скриптом `scripts/generate-rest-sound.mjs`, без сторонних семплов.

Звук можно прослушать или отключить в настройке таймера конкретного занятия.
Он не заменяет звуки уведомлений расписания и самочувствия. Таймер и этот
сигнал работают в открытом приложении; доставка сигнала при выгрузке приложения
из памяти не реализована.
