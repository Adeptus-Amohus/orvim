# Fairy и Warm Keys — доработка

По три варианта двух выбранных пользователем звуков. Исходные версии из `v2` сохранены.

## Fairy — для самочувствия

1. `fairy-01-soft.wav` — нежнее, сглаженная атака, мягкая подложка, 1,95 секунды.
2. `fairy-02-sparkle.wav` — чуть ярче, перелив завершается дополнительной нотой, 1,85 секунды.
3. `fairy-03-short.wav` — компактный исходный мотив с меньшим эхом, 1,25 секунды.

## Warm Keys — для расписания

1. `warm-keys-01-velvet.wav` — бархатные клавиши с более плавной атакой, 1,95 секунды.
2. `warm-keys-02-bright.wav` — светлее, с мягкой завершающей нотой выше, 1,8 секунды.
3. `warm-keys-03-short.wav` — короткий тёплый сигнал, 1,15 секунды.

WAV: PCM 16 bit, stereo, 44,1 кГц. Пиковые уровни одинаковые — 0,26.
Генератор: `scripts/refine-notification-candidates.py`, Python + NumPy.
Звуки пока только для прослушивания и выбора.
