# Short и Velvet — близкие вариации

Доработка выбранных Fairy Short и Warm Keys Velvet. Исходники сохранены в `v3`.

## Short — для самочувствия

1. `short-01-smooth.wav` — плавнее, тот же короткий мотив, 1,25 секунды.
2. `short-02-resolved.wav` — более завершённая последняя нота, 1,25 секунды.
3. `short-03-compact.wav` — компактнее, меньше эха, 1,05 секунды.

## Velvet — для расписания

1. `velvet-01-warm.wav` — теплее и мягче, 1,9 секунды.
2. `velvet-02-full.wav` — более полный аккорд и чуть больше пространства, 2,05 секунды.
3. `velvet-03-simple.wav` — лаконичные клавиши и спокойное затухание, 1,7 секунды.

WAV: PCM 16 bit, stereo, 44,1 кГц. Пиковый уровень 0,26.
Генератор: `scripts/polish-selected-notifications.py`, Python + NumPy.
Выбраны `short-03-compact.wav` для самочувствия и `velvet-01-warm.wav`
для расписания. Их рабочие копии находятся в `../../notifications`.
Остальные варианты остаются образцами для прослушивания.
