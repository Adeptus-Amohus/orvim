# Вторая подборка звуков

Оригинальные короткие мелодии с характером добрых приключенческих игр:
окарина, арфа, музыкальная шкатулка и мягкие клавиши.
Мягкая атака, центральная мелодия и тихое стерео эхо.
В уведомлениях ещё не включены: выбор после прослушивания.

## Самочувствие

1. `wellbeing-01-fairy.wav` — Маленькая радость, 2 секунды.
2. `wellbeing-02-ocarina.wav` — Окарина, 1,95 секунды.
3. `wellbeing-03-musicbox.wav` — Музыкальная шкатулка, 2,1 секунды.

## Расписание

1. `schedule-01-harp.wav` — Тихая арфа, 1,55 секунды.
2. `schedule-02-warm-keys.wav` — Тёплые клавиши, 1,65 секунды.
3. `schedule-03-forest.wav` — Лесной зов, 1,65 секунды.

WAV: PCM 16 bit, stereo, 44,1 кГц. Пиковый уровень 0,26.
Генератор: `scripts/create-friendly-notification-candidates.py`.
Для генератора требуется NumPy. Для воспроизведения нужны только WAV файлы.
